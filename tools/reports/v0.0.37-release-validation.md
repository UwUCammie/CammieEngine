# v0.0.37 release validation

This user-authorized incremental alpha adds Freeplay library management and base game duplicate hiding, revises several Freeplay visuals, makes cutscenes skippable with Enter, and fills general gaps in the Psych and Nightmare Vision compatibility layers that were found with two imported songs. Remaining roadmap requirements stay open.

## Build and regression evidence

The final Windows build completed successfully. Its executable SHA-256 is `e4f3eafd8bf97db089ad9f14eb5f39a4bfc418e630182eca7bc2ab565e92cfc3`.

The full suite executed 2,895 tests across 981 modules in 373 seconds with 347 fixture/platform skips and zero failed modules, through `run.bat package`. A first packaging attempt stopped on one failed module: `test_import_removal_manager.py` exceeded its 15 second interpreter timeout while the machine was busy. It passed alone and in three other full runs of the same tree, and the area it covers was not changed.

Seven modules failed in an earlier full run because they pin exact text of code this release touched. The pause gate text and the update prologue were restored to their pinned form, the video sprite no longer names `PlayState` directly, and one stub gained the two decoder fields now read.

One pinned expectation was changed on purpose. `test_source_owner_asset_context.py` required the OpenFL facade of a Nightmare Vision import to reject every file when the import has no asset index. It now requires each facade to read its own scope of such an import and still reject the other scope. The Lime facade and indexed imports are unchanged.

## Freeplay

Unit checks cover the deterministic star stream, the layout, hidden chart and mod state, mod names, the duplicate rule and the tempo pulse. A native framebuffer from an earlier build of this tree confirmed the bottom right heading, the coloured key hints, whole numbers inside compact stars and the star stream.

Against a private copy of a real library the duplicate rule hid 19 imported copies of base game charts and kept a same-titled chart with its own cast, remixes and unrelated charts. The library menu, duplicate hiding in the live list, the option toggle, the pulse with a playing preview and loudness colours with audio were not inspected natively.

## Cutscene skipping

The landing rule is unit checked: end of the cutscene, or one second ahead of the next player note, never backwards and never for a video that plays behind notes. In native runs the skip took an opening script video from 1.5 s to 11.1 s and a mid-song script video from 305.0 s to 313.9 s, one second before the next player note, and the source end callbacks ran both times.

A hidden window cannot receive key presses, so those runs called the same routine through a harness hook. A physical Enter press, chart event videos and intro videos were not exercised natively. Dialogue, scripted cutscene timelines and Codename cutscene states are unchanged.

## Imported script compatibility

All changes are general engine or compatibility behaviour. Two imported songs served as test cases, run muted on a private desktop against a private copy of a library.

A Nightmare Vision stage that aborted on its first atlas now completes its setup: its opening video plays, its mirror layer stays in the world because `camFollowPos` exists, and its opponent strumline is drawn by the script camera. Its double-note afterimages match the reference engine source and were left as they are. Its ending launches a program bundled with the mod; the engine does not run executables shipped inside imports.

A Psych song whose scripts read `dadName`, resize a full screen sprite with `setGraphicSize` and use a bare `return` before `elseif` now shows its effect full screen and attaches its swinging sprite to the character. With those scripts running, two native crashes appeared and were fixed: a negative animation frame index, and a sprite destroying itself in its own animation finished callback. The song then ran 47 seconds without a crash. One script error remains on a non-sick hit, where the script reads a fourth judgement window that does not exist here.

Five other scripts of that pack still fail translation (unbalanced `end`, `_G` lookups) and were not addressed.
