# Historical NV singing and ghost animation

Local v0.0.23 development. No push or publication.

## Scope and shared services

Pinned reference: Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, historical PlayState singer branches, Character ghost animation and Note links.

Historical default handlers now preserve source owner/GF selection, player animation locks, opponent voice-line interruption, distinct Hey/noAnimation ordering, section/type alt suffixes, chord selection and onGhostAnim admission. They use native Character playback through a source-version decision adapter. Modern field singer routing remains unchanged. Generated historical heads receive source row membership and head/sustain links; source-created notes with explicitly supplied predecessor arguments still require complete constructor comparison.

Ghosts share the actor atlas but own their animation controller. The shared renderer service copies source scale, flip, tint and animation offsets, uses Flixel's linear 0.75-second/45-pixel tween, reuses four slots and tears down owned sprites/tweens. Shader and camera state retain the source defaults. Current Flixel's ONESHOT manager performs completion destruction after the callback; destroying the tween inside that callback, as the older donor did, would clear its manager before removal. Missing slots and unsupported animation directions produce attributable errors. These safety/lifecycle adaptations do not claim parity with source null dereferences.

Historical dance locks now honor animTimer and voicelining; animation timers run without modern CharacterData and do not pause on a '-return' name. Historical Hey durations use elapsed time without modern playback-rate scaling. Complete Character.update/special-animation expiry ordering, debug/current-animation gates and forceDance semantics remain a separate comparison, not certified by the singer tests.
