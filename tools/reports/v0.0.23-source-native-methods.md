# Shared source/native method boundaries

10 October 2026, local v0.0.23. No push, tag or release.

ScriptClassScope now owns a cached adapter for selected native group and tween methods. Iris property reads, its Type/Reflect facade, and HScript-ex native and inherited method reads use that one adapter. Capturing a method or borrowing it through reflection therefore retains its original receiver and argument conversions. Repeated reads retain wrapper identity; a retained wrapper rejects calls after its caller scope is released.

The adapter reuses the existing group/tween conversion and recycle services. Native group results and indexed bridge reads expose their source object rather than the FlxBasic bridge. Group callbacks preserve source identity. Explicitly passed objects from another source session convert through their actual active owner, so the borrower does not take over lifecycle or static storage. A released or unowned source target is rejected. This supersedes earlier tests that refused all cross-scope object use; imports and class registries remain isolated.
