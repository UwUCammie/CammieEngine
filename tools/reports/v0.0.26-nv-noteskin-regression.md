# v0.0.26 NV noteskin regression checkpoint

11 October 2026. Compatibility evidence for the user-authorized v0.0.26 release.

## Cause and shared repair

`NightmareVisionPaths.noteskin()` selected the historical script API from the HUD artwork layout. A modern source API can legitimately use historical HUD artwork. In this mixed layout the lookup skipped the authored JSON noteskin, selecting fallback note textures, splash prefixes and sustain-effect offsets.

Select the noteskin API from the retained source API profile instead. Reuse the existing profile read during Paths construction. Keep HUD artwork selection independent. There are no song/package names in the production fix and no donor chart, script, atlas or shader changes. Valid existing imports use their retained definitions without a new conversion.

The fallback splash atlas did not contain the requested animation prefix. Visible splashes consequently had no running animation to finish and retire; the growing pool was revisited every update. Loading the correct skin restores normal source animation completion, without arbitrary timeouts or hiding effects. The authored sustain loop offset is restored too (`[-10, 15]` instead of the fallback `[45, 35]`).

## Native verification

All runs used an isolated runtime, a private never-activated Windows desktop and muted audio. Timed runs used 1920x1080, gameplay shaders enabled, full quality, zero background/highway dim and no framebuffer capture. Private settings and binaries were restored after comparisons; the user's playing install was untouched.

Accelerant, hard, 135 seconds, 480 FPS cap, same retained package:

| Song interval | v0.0.25 median FPS | Candidate median FPS | v0.0.25 post-phase ms/update | Candidate post-phase ms/update |
|---|---:|---:|---:|---:|
| 0-10 seconds | 423.5 | 442.0 | 0.305 | 0.108 |
| 55-65 seconds | 149.0 | 449.5 | 3.671 | 0.086 |
| 115-125 seconds | 63.0 | 444.5 | 9.373 | 0.145 |

The post phase includes the splash-position traversal and generic post hooks, so it is not pure script execution time. Median asynchronous GPU query time at 115-125 seconds was 0.125 ms in v0.0.25 and 0.104 ms in the candidate. This reproduced slowdown primarily tracks CPU work from accumulating invalid splashes.

Candidate player pools stayed bounded at four tap slots and three sustain slots; opponent pools at one tap slot and two sustain slots. Tap pools include the intentionally invisible, animation-less source seed, which is preserved. Ordinary visible splashes use four frames at 24 FPS, advance and retire normally.

Separate 60 FPS visual-only runs confirmed authored notes/receptors and the Try Harder ice-note graphic. Live native observations resolve special notes to `images/UI/game/notes/accel/NOTE_assets.png` and `images/UI/game/notes/ice/NOTE_assets.png`. The authored splash prefixes and sustain offsets are loaded. These are representative checks, not certification of every NV song or every animation frame.
