## Contract and implementation

Reference: NightmareVision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/Note.hx` (`reloadNote`, `_loadPixelNoteAnims`) and `source/gameObjects/StrumNote.hx` (`reloadNote`). This is the historical source profile, not the current JSON noteskin contract.

- Psych and historical NV share `SourcePixelNoteFrames` for four-column sheet slicing and native frame-index animation installation. Psych retains its existing validation and 24 FPS note defaults; historical aliases use the source 30 FPS defaults. Up-lane confirmation uses 12 FPS, other lanes 24 FPS.
- Historical taps and receptors load five-row sheets; sustains load two-row `ENDS` sheets. PNG-only graphics resolve through the existing authenticated owner/core path rules. A partial owner atlas cannot combine with another root, and sibling packages cannot supply missing graphics.
- Quant selection uses the existing source preference/classification helper. Heads and tails independently select an available quant graphic; a missing quant tail uses its own ordinary tail. `canQuant` opt-out is preserved.
- Historical reloads preserve vertical hold scale, source raw/base scale, prior animation and the replaceable pixel X offset. Pixel antialiasing is disabled as in the source. Initial generation, field reloads and script texture reloads use the same shared skin entry point.
- Existing historical sustain construction and perspective rendering remain responsible for body/cap scaling and projection. No chart names or donor edits were added to production behavior.

## Limits and next work

The native probe explicitly sets a test-only pixel-stage flag in a disposable runtime. It reuses authenticated retained pixel sheets without editing donor content. It verifies raster loading and rendering, not authored pixel-stage activation or full-chart parity. Its old isolated runtime version label comes from retained runtime metadata, not the newly built executable.

The pinned source assigns `PlayState.isPixelStage` through `setStageData` during initial setup (lines 420-423 and 708-709) and restores the stage value in `switchTo` (lines 5645-5647). The current host still starts from its UI pack flag. Implement the historical stage-data/script-property lifecycle next, respecting source ordering and profile boundaries; then verify an authored pixel stage and state exit. Check stage replacement separately against the selected source contract. Do not hide this dependency behind the synthetic probe.

Source note-type `loadPixelNoteAnims` overrides, noteskin splash/quant callbacks, splash constructor/setup overloads, live wider-key/source-created/recycled note contracts and modern JSON pixel skin support remain open. Native quant raster checks remain open; current quant selection proof is executable headless coverage.
