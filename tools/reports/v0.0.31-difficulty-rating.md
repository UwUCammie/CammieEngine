# v0.0.31 Difficulty Rating checkpoint

12 October 2026. This is a bounded implementation and regression checkpoint, not release validation or a completed compatibility/performance roadmap.

The host browser displays an integer **Difficulty Rating X/20** beside each difficulty star and in the selected-chart details. The existing color spectrum and star presentation use the composite rating. The legacy `npsHigh`/`npsLow` preference IDs now have Difficulty Rating labels, retaining saved sort preferences, unknowns last and favorites first. Separate authored ratings retain their original scales.

`ChartDifficultyAnalysis` revision 6 analyzes player-controlled chart heads. Opponent and autoplay fields are excluded. Sustains contribute activity and overlap without inflating head counts. Average NPS uses merged playable intervals with a one-second margin around heads; long empty gaps and initial silence do not dilute the rate. A two-second peak captures bursts, while the root-mean-square rate of active ten-second windows captures varying sustained density. NPS retains full precision and displays two decimal places.

The composite also includes avoid-note frequency and severity, hazards in fast sections, chord frequency and distinct lane count, the longest sustain in each chord, local speed relative to the chart, and notes played on another lane while a sustain remains held. Required notes with enhanced miss damage remain in player-head and chord counts and add separate miss pressure. Native mines deal ordinary damage; native nukes and explicit health depletion of at least the default two-health capacity count as lethal. The pressures compound before rounding and clamping to 1-20; an empty chart receives 0. Scroll speed contributes nothing.

This is a static estimate. Unknown custom note kinds and callback behavior are labeled estimated; analysis never executes donor scripts or infers their health effects from song/mod names. Runtime health settings, arbitrary scripted threats and subjective rating calibration are not certified. Lengthening an existing long break and shifting initial silence leave the tested rates/rating unchanged. Splitting an uninterrupted pattern adds section-boundary padding and can slightly change its estimate. Legacy inputs beyond the bounded chart/metadata read limits are skipped with warnings in the receipt rather than disabling the mod.

Normal imports and source refreshes create sidecars before publication and stamp the analysis revision separately from importer revisions. For an analysis-only revision, background receipt inspection reads installed charts and note metadata, then publishes only derived sidecars through the shared recoverable transaction. Authenticated, unchanged owned-file receipt entries carry forward without copying or claiming current chart/media bytes. Input containment, size checks and before-publication drift checks remain enforced; local sidecar edits cause a conflict. Main-thread Freeplay generation handling invalidates cached values after publication. Imported charts do not fall back to parsing the whole library while sorting.

Verified evidence:

- `test_chart_difficulty_analysis.py`: 7 tests passed, including ownership, initial silence, long-break length, sustains, chords, hold/tap overlap, ordinary versus lethal damage, healing, miss-risk heads, scroll-speed independence and integer range validation.
- `test_library_sorting.py`: 2 tests passed.
- `test_chart_difficulty_refresh.py`: 1 migration test passed, covering sidecar ownership, importer/media preservation, version no-op and edited-sidecar conflict. Its full-run Windows path failure was corrected by honoring the runner's short scratch directory.
- `test_import_refresh_transaction.py`: 23 tests completed successfully (22 passed, 1 environment-dependent skip). Added coverage verifies carried receipt entries and edited assets remain unchanged, case collisions are rejected, and an interrupted additive commit restores prior output and receipt state.
- `test_import_refresh_manager.py`: the native 68-test suite passed on isolated retry using a short canonical fixture cache. One additional migration test passed in both native and eval: an installed normalized chart acquired a version-6 integer rating before owner readiness, generation advanced, and chart bytes, registry bytes and the complete importer record remained unchanged.

The integrated suite initially reported failures and its final resolution belongs to the overall feature validation checkpoint. This report makes no native Demon gameplay, loading-artwork, controller/viewport, corpus-wide performance or publication claim. All broader optimization and compatibility goals remain open.
