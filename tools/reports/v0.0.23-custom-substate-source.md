# Psych native custom-substate contracts

Local v0.0.23 development; full-roadmap publication gate unchanged.

## Source and implementation

Pinned Psych revision `5c67ced49e5a98535298a6daa3f8f4ec79ac8399`, `source/psychlua/CustomSubstate.hx`, with its PlayState callback broadcaster and native pause/open/close boundaries.

Modern Lua, HScript presets, source imports and class reflection now share the native PsychCustomSubstate class. Its source constructor accepts a name, publishes the static name and HScript name global before superclass construction, and leaves the instance unpublished until create. The native instance and name are writable source statics. The existing class retains an explicit historical owner-clock adapter; donor files and chart/mod-specific production paths are unchanged.

Creation, update and destruction select the live PlayState for each source operation. Callback arguments read the current static name, including changes made between lifecycle calls. These operations reuse PsychRuntimeBindings' source broadcaster, preserving family ordering and stop/result rules instead of using the generic host broadcast. Shared family publication also powers the existing setOn callbacks; custom-substate globals reach HScript only.

Public close acts only on a published instance and calls the current PlayState. Public insertion checks the published instance before looking up the active MusicBeatState variable map, keeps source FlxObject casting and add/insert semantics, and is shared between Lua and HScript. Modern open preserves existing paused state when pauseGame is false; pausing follows source camera/state/music/vocal ordering through host-native audio operations. Host bookkeeping handles Flixel 6 deferred opens without publishing queued instances. Modern countdown resume follows the native timer path; historical pauses retain their task snapshot restoration.

Parent teardown publishes the destruction callback and clears source globals while interpreters remain alive. Later native disposal suppresses duplicate notifications. Direct destruction of a constructed source instance still dispatches the source destruction path. Cancelled, uncreated Flixel queue entries remain an explicit host adaptation.

These are source-contract comparisons, not donor-rendering proof.
