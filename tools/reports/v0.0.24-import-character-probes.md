# Character implementation probe cleanup

Local v0.0.24, 10 October 2026. Shared importer change only; no chart, mod, donor or playing-install changes.

## Change and preservation

Character implementation discovery previously checked every candidate on disk before inspecting its kind. Native char.png/char.xml candidates additionally performed paired case-insensitive lookups whose successful and unsuccessful branches both continued without accepting the character. The implementation check now filters candidates lexically first and removes those ineffective paired lookups. It still accepts the same legacy character sprites, HXC definitions, custom-character scripts and script/JSON implementations with their required directories. Registry-backed atlas validation remains in characterRegistryVisualFound.

Candidate arrays and diagnostic search paths are unchanged. Every eligible file is checked live, including repeated checks after deletion/recreation; this adds no filesystem-result cache. Null/empty candidates remain rejected. Regression coverage includes case and separator variants, bare atlas rejection, required directories and native aliases.
