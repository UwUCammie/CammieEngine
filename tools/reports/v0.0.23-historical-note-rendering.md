## Historical HSV/HSL integration

The source-selected historical profile now binds `NightmareVisionLegacyColorSwap` to individual notes and receptors through `NightmareVisionRGBGraphics`, which remains the shared draw path. Modern owners retain RGB. `noteSkin` is an owner-persisted preference with the historical `Vanilla` default. `Quants` and `QuantStep` reuse the existing subdivision classifier and sustain inheritance. A quant texture is admitted only when its exact owner-scoped `QUANT` atlas exists; an absent variant retains the authored texture and lane HSV.

`NightmareVisionLegacyNoteColors` initializes lane/quant HSV at the historical type-assignment boundary. Custom setup runs afterward, and its splash values and texture remain authoritative. Spawn does not reapply preferences over script mutations. Repeating a type assignment resets its source defaults without running setup again. A changed built-in type bypasses custom setup; changed hurt types reload the HURT atlas and reset HSV, whereas repeating that setter restores the source lane defaults. Receptor confirmation receives the hit note explicitly; static animation resets colors, and a call without a note uses lane preferences rather than the modern last-note fallback.

Historical gameplay splashes reuse the owner atlas loader and native splash pool with the source HSL shader, saved hue/saturation/lightness, animation prefixes/variants, opacity and frame-rate rules. Their authored texture can be set per note. Recycled splash checks cover texture/color replacement and shader teardown. The smoke diagnostic records historical uniforms alongside the existing modern RGB fields.

Validation for the implemented color path is complete; the remaining source contracts below are still open. The full regression run executed 2,650 tests across 847 modules, with 344 documented platform/corpus skips and one fixture compilation failure caused by its missing `noteSplashTexture` field. ### Remaining source contracts

This integration does not certify complete historical rendering or whole-chart parity. Pixel head/tail sheets, field-wide scaling/layout, the old script-facing splash constructor/setup overload and automatic historical bare shader presets still need source-matched adapters. Direct shader-uniform mutation followed by an equal-value HSL setter is not yet compared with the historical source. Full note-pool recycling, source `noteScript` pointer clearing on repeated assignment, and the broader built-in Ghost/Slam note behavior need dedicated lifecycle coverage. The generated GPU probe covers shader math and owner isolation; it is not a receipt-import or complete gameplay test. Advanced Animate, embedded/custom-library support and all later roadmap phases remain open.
