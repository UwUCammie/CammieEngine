# Historical Lua object ordering

Local v0.0.23 development. The full-roadmap release gate remains in force.

## Shared contract

Pinned source: Nightmare Vision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/data/scripts/FunkinLua.hx`, getObjectOrder/setObjectOrder and their lookup helpers.

The public historical Lua callbacks use shared raw reflection for tags and nested array/map paths. They preserve the initial root lookup followed by a second lookup for nested paths. Missing objects return -1 or leave the scene unchanged with a diagnostic. Object lookup and scene membership are distinct: an unmounted tagged object can still be inserted.

Ordering reads the active scene, including game over. Removal is unconditional for a resolved object and insertion uses a fresh active-scene lookup after removal listeners. Positions go directly to the native insertion API, preserving that API's own behavior instead of clamping them in the adapter. Native scene storage, rendering order and object ownership remain shared with the engine.

Installation occurs after the general Psych binding overlays. Other profiles, HScript interpreters and results observers retain their existing callbacks. No chart/mod branch, donor change or replacement scene implementation was added.
