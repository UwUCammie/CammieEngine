# v0.0.40 release validation

This user-authorized incremental alpha shares one implementation between the Psych and Nightmare Vision layers wherever the two engines behave the same, routes the Psych, Nightmare Vision and V-Slice layers through base game functions (adding them where none existed), widens Lua, V-Slice and importer compatibility, reduces stutter sources, and lets the in-game removal tool delete broken and linked mods. Remaining roadmap requirements stay open.

## Build and regression evidence

The final Windows build completed successfully. Its executable SHA-256 is `06dd7bc8dc16a8ef688e331d1de556fc9adf955f8651c00847bcdff973f231c6`.

The full suite executed 3,144 tests across 1,068 modules in 431 seconds with 347 fixture/platform skips and zero failed modules, through `run.bat package`.

The first packaging attempt stopped on two modules, both timeouts rather than failures of what they check: `test_import_removal_manager.py` waited 2 seconds for its worker and `test_import_refresh_transaction.py` waited 3 seconds for cleanup to resume after gameplay. Both pass every time alone. The waits are now 30 second upper bounds; the tests still require the work to pause during gameplay and finish afterwards.

Before packaging, a whole-project type check passed and the focused tests for every changed file passed (1,023 modules, run once after the last change, with three stale source-text checks updated to follow code that moved).

## Native checks

Muted runs on a private, never activated desktop against a private copy of a real install, compared with the v0.0.39 binary on the same songs:

- Two Psych songs and two Nightmare Vision songs load and play in both builds, with identical log errors.
- A third Psych song now runs a rating script that the old translator disabled. That script errors on note hits because the member index passed to `goodNoteHit` does not point at the hit note; this is recorded as a follow-up, not a regression in play.
- With frame pacing telemetry on a script-heavy Nightmare Vision song, in-song frames over 33 ms went from 14 (v0.0.39) to 6. Spikes of about 95 to 123 ms at fixed song positions remain in both builds and are the next stutter target.
- One earlier run of that song fell to 1 FPS; two reruns of the same build ran at 60 FPS, so it was treated as environmental.

Not verified natively: V-Slice songs (none in the private copy), physical input, the two step removal confirmation with linked packages (unit tested; the single step dialog was captured natively), and audio behaviour of tagged sounds, split vocals and dialogue music.
