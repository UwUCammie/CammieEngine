# Psych custom-substate parent teardown

Local v0.0.23. Publication remains gated on the entire roadmap.

## Behavior and source boundary

Pinned Psych revision `5c67ced49e5a98535298a6daa3f8f4ec79ac8399` closes and resets its published custom substate at the beginning of PlayState.destroy, before script release. Previously the host only notified the adapter's latest target. With a queued replacement, this could omit the still-mounted child, and native child disposal happened after script providers were released.

PlayState now performs the source close/reset sequence while scripts and audio remain available. The shared teardown path also checks both the adapter target and Flixel's actual requested substate, covering direct source-class construction. Distinct uncreated targets are cancelled once without creation callbacks. Mounted native children are disposed before parent script cleanup, and registry references keep their source lifetime semantics. Historical owner-clock substates retain notification-before-native-disposal behavior.

Cancelling an uncreated replacement is an explicit host queue-lifetime adaptation. It does not claim that the pinned donor's raw deferred replacement queue has identical behavior during parent destruction. Normal source close/reset order is compared directly with the pinned source. No chart/mod-specific production branch, donor edit or asset change is involved.
