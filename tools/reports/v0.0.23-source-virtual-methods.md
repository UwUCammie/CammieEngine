# Shared source virtual method checkpoint

10 October 2026, local v0.0.23. No push, tag or release.

The owner-scoped HScript-ex bridge now resolves an inherited unqualified instance-method call through the most-derived source object. This includes calls during parent construction and private overrides. Static method calls remain bound to their lexical declaring class, and explicit super calls retain their parent implementation. Local callable arguments retain precedence. Captured methods now use the shared variable-argument bridge instead of rejecting declarations with more than four parameters, preserving authored optional defaults.

The loader also wraps a compact superclass constructor as a complete block. Removing only its semicolon allowed subsequent expression-body normalization to consume the next method declaration. Expression-bodied methods returning simple arrow function types now locate the real body correctly. Both changes apply to imported source modules generally.

Validation compares the same three-level class hierarchy compiled by Haxe 4.3.6 with the actual owner-scoped loader. Seven result sequences cover constructor dispatch, bare/this/inherited/private calls, lexical statics, captured methods, explicit super calls, six arguments, omitted defaults, local callable shadowing and exception recovery. Native checks use the same classes and an independently compiled expected result. No donor chart or asset changes are involved.

The first interpreter run exposed the compact-constructor and arrow-return normalization gaps; both are corrected. The first native comparison had identical values but failed because the disposable expected-results file used CRLF while the runtime joined values with LF. The fixture was normalized to LF without changing the executable.
