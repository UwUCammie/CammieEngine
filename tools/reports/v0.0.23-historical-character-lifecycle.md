## Source behavior and integration

Pinned reference: Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/Character.hx` update and dance.

Historical characters now run source-version decisions before and after the shared native animation update. Animation timers, Hey expiry and completed special animations preserve their original order and debug/current-animation gates. A positive Hey timer does not fall through to the finished-special branch on its expiry frame. Timed dance uses the historical default force value rather than the newer forceDance field. Opponent sing duration uses the source isPlayer split and 0.0011 step-duration factor; player actors do not inherit the opponent timeout. The original loop transition runs before native frame advancement, and hold-start completion runs afterward. Historical update no longer inherits newer return/holding behavior or host-specific miss/death/hold fallbacks.

Historical dance honors the mutable danceIdle flag, alternates the source side, ignores forced playback and only plays an existing suffixed idle. It does not add an unauthored plain-idle fallback. Native animation playback, atlas ownership, ghosts and rendering remain shared services. Existing host update hooks remain present; imported scripts/assets are unchanged. Null animation controllers receive a host safety return in the source decision helper.
