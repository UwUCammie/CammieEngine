# Uniform-loop shader experiment and fidelity gate

Local v0.0.24, 10 October 2026. The proposed optimization was rejected and removed from production source. This checkpoint adds no GPU speedup and does not resolve the laptop slowdown.

## Experiment

The shared optimizer experiment recognized simple integer loops from zero to a uniform bound, expanded the first 32 iterations into guarded blocks, and kept the original residual loop above 32. It did not reduce particles, samples, resolution or update frequency. It rejected loop-index writes, early exits, nested control flow, macro aliases, writable function parameters and excessive generated code. Two focused checks passed, and the native Windows build compiled successfully. It remained disabled in ordinary gameplay throughout the experiment.

Correct iteration counts did not prove visual fidelity. Making the iteration index a compile-time constant changes which floating-point expressions the driver can pre-evaluate. The shader's trigonometric/hash calculations are sensitive to those differences. Constant folding is the likely cause of the observed changes, but individual compiler operations were not independently isolated.

## Native output comparison

The full-quality native comparator rendered reference and candidate side by side at six fixed times (0, 1, 10, 80, 175 and 230 seconds), with loop counts -1, 0, 1, 30, 32, 33 and 64. Both sides used identical dimensions, textures, time and uniforms. The input was non-saturated; observed reference background was RGB 127 and positive-count peaks reached RGB 242, so clipping to white did not hide particle differences.

All 42 captures completed on a muted, never-activated private Windows desktop. Each comparison used 441,600 pixels, excluding the bottom 30 rows occupied by the separate MUTED overlay on the right. Negative and zero counts matched. Positive counts changed particle positions and sizes, confirmed by viewing the native capture. For counts 30 and above, approximately 1.4-2.2% of compared pixels changed. The worst capture was `case-5-time-80.png`: 9712 pixels (2.199%), with a maximum single-channel difference of 115. Low average error does not make these displaced particles acceptable. No speed test or production enabling followed this failed visual gate.

The experiment was archived only under `tmp/v24-uniform-loop-rejected/`; its method, environment switch and dedicated test were removed from the engine/test paths. Existing nearest-distance optimization behavior remains unchanged. No authored chart, stage, shader asset or mod-specific runtime branch was added or changed.

## Reusable diagnostic improvement

`RuntimeShaderCompareState` now accepts optional `CAMMIE_SHADER_COMPARE_CONFIG` JSON with fixed uniform cases, float/int values, time-uniform names, input dimensions/color and an explicit ready-to-compile `candidatePath`. Without that configuration, its existing nearest-distance comparison mode remains available. It saves both shader sources and completion metadata. This is an opt-in diagnostic and does not affect normal gameplay.

The final comparator reproduced all 42 earlier captures byte-for-byte at the pixel level when given the archived generated candidate. Its original mode also completed six cloud captures with identical compared RGB values. These checks validate the tool, not the rejected shader optimization.

## Validation and next work

Canonical Windows build passed. The full suite ran 2,753 tests across 924 modules in 342.8 seconds, with 347 skips and zero failures. Three skips were native C++ cases because the portable compiler was absent from PATH; both affected modules were rerun with that compiler and all six tests passed. The other 344 platform/donor skips remain. No performance timing was inferred from the fixed-input runs performed while the suite was active.

Next investigate shared reductions that retain runtime evaluation of hash/trigonometric expressions, or independent cloud/fog work. Do not re-enable this loop expansion based on CPU/algebraic equivalence or mean image error. Require a new native visual result and meaningful GPU improvement. Large-library refresh waits and all broader compatibility, imported-menu, mod-management, Freeplay and fidelity goals remain open. Nothing was pushed or published.
