# Historical NV default hit control flow

Local v0.0.23 development. No push or publication.

## Contract and shared implementation

Pinned reference: Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx` default field creation, goodNoteHit, opponentNoteHit and StrumPlayAnim, plus `source/gameObjects/Note.hx` update.

The historical default fields now receive distinct fixed callbacks before receptor-generation hooks. Their identity does not depend on later field control/ID changes, and they use the field passed by the caller. Input admission and script callback replacement remain in the existing shared field adapter. A small historical flow calls the existing score, miss, actor, audio, notification and retirement services in source order; the modern signal route remains independent.

Player handlers preserve the already-hit score-refresh path, autoplay ignore/hazard early return, hit-sound preference, confirmation-before-hazard behavior, head combo/scoring before health, exact hitHealth times healthGain, and source flags before notification. Historical canMiss is not an autoplay rejection. Hazard completion retains splash/hurt and retirement without successful-hit notifications. Opponent handlers restore source voice/confirmation ordering, set hitByOpponent before notifications without immediately setting wasGoodHit, and do not apply player health/scoring. Historical Note.update commits wasGoodHit after its script update. The writable doAutoSustain flag is set for source lanes above four; consuming that flag in all manual wider-key paths remains open.

Historical receptor confirmation uses the source key modulo for autoplay and live receptor IDs for manual hits. Its source 0.15/0.30-second reset does not inherit modern playback-rate scaling or field playAnims gates. Host observers keep the fixed handler family and no longer repeat historical camera/audio effects after scripts.
