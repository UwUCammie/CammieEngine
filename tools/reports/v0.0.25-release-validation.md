# v0.0.25 release validation

11 October 2026. User-authorized incremental alpha release, including the native pause-input repair and verified imported-menu discovery/order checkpoint.

- Canonical `run.bat package` passed. The current Windows x64 build was reused after input validation; the full suite passed 2,775 tests across 933 modules in 394.6 seconds, with 344 environment-dependent skips and zero failures.
- ZIP CRC, SHA-256, clean committed options, release tag, update log and runtime hashes passed. All 1,732 paths are safe and have no case-insensitive collisions. Developer imports, caches and temporary files are excluded.
- The exact extracted package passed muted Freeplay and Tutorial pause-input checks on a never-activated private Windows desktop. At both 60 and unlimited FPS, two cycles opened pause, navigated Down/Up, verified the paused audio clock and resumed with Enter. All processes exited zero and reported success. The child PATH contained only Windows system paths, so development toolchain DLLs were not supplying missing package dependencies. Extracted settings were restored.
- Microsoft Defender found no threats in staged project/build-tool files or the freshly extracted final package, using custom scans with remediation disabled. The direct large-ZIP scan was skipped by Defender and is not counted as a successful scan; the extracted-content scan completed successfully. No security settings changed. See `v0.0.25-security-review.md` for scope and limits.
- Release entry names match v0.0.24 exactly. Among executable, library and launcher/script surfaces, only `Funkin.exe` changed; updater and runtime libraries are byte-identical. This is a change inventory, not independent reverse engineering of dependencies.
- Protected-file verification checked 70 baseline files. There were no new changes; the sole historic difference is the previously authorized private visual-test options baseline. Text-policy and whitespace checks passed.

Remaining GPU/CPU performance work, laptop verification, residual refresh stalls and all unfinished compatibility/UI roadmap gates remain open. This publication does not certify every imported custom pause menu or finish the roadmap.
