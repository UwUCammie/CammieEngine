The supplied Psych HealthIcon/Alphabet and NV HealthIcon/RGBSprite/note classes demonstrate these override contracts; no production mod/song identifiers or donor edits were introduced.

The durable HScript-ex patch now finds the declaring source class for plain, compound and increment writes, including explicit this.field writes. Arguments keep their local storage. Native construction callbacks before adapter binding still delegate to native implementations; authored construction-time virtual override parity remains open.
