# Compiled Lime asset manifest checkpoint

Development: v0.0.22, 9 October 2026. Shared importer and compatibility changes only. No donor edits, authored chart conditions, guessed IDs or manual owner-sidecar patches.

## Contract and implementation

Pinned Lime 8.3.2 `AssetManifest.hx`, `AssetHelper.hx` and `ManifestResources.hx` establish the emitted manifest format, manifest-relative root resolution and `manifest/<library>.json` registration convention. Published flxanimate 3.0.4 `frames/FlxAnimateFrames.hx` establishes unnumbered then contiguous numbered spritemap discovery and each map's `meta.image` filename.

`SourceCompiledAssetManifest` accepts anonymous serialized version 1/2 tables and direct version 3 JSON tables. Serialized class hooks, cycles, nested object fields, sparse-array allocation and trailing payloads are rejected. Byte, asset-count and work limits apply. `SourceCompiledAssetProfile` authenticates all consumed manifests against the retained receipt, confines paths to the selected source root, preserves IDs, declared types, libraries and later-record shadowing, and reuses `PsychAssetProfile` candidates. An authored Project.xml retains priority. Custom library loaders and executable-embedded bytes are not guessed.

The profile goes through the existing shared mapped publisher, staged writes, owner identity sidecars and package/core handoff. Compiled file catalogs do not claim authority over unrelated filesystem mod assets. Entire libraries can be embedded in the source executable, so file manifests do not claim a complete library-registration set. Known file identities remain usable in partial catalogs; absent or unsupported identities remain explicit uncertainty. Psych revision 11 and Nightmare Vision revision 15 schedule retained imports for regeneration.

The shared composite publisher also lets its identity policy handle explicitly declared TEXT/BINARY data when a directory-based media heuristic disagrees. A CSV or video under an images directory is not automatically an image. Standalone media validation and unresolved owner scopes retain their existing checks.

`SourceAnimateAtlasLoader` no longer depends on complete Assets enumeration. It requests exact map IDs in historical source order and loads each declared image through the captured owner Assets service. The shared renderer, owner lifetime and cache separation remain unchanged.

## Remaining scope

Imported menu flows, mod management, favorites/categories, dense Freeplay with correct icons/stars, independent group/chart sorting and quality-preserving performance remain required. The user authorized publishing v0.0.22 after this checkpoint. Donors and the playing install remain unchanged.
