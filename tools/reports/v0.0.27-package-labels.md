# v0.0.27 package labels

12 October 2026. Shared host library/menu presentation; no source mod changes.

## Contract

The installed private test library contains two separately owned packages titled
SEGATENDO COLLECTION. Freeplay source captions, Imported Mods subtitles and
category membership rows now share a short badge derived from the normalized,
retained package owner. Authored package and chart names remain intact. The badge
is display/search metadata only: full owner roots still govern membership,
favorites, readiness and launching. No registry, provenance, chart or save-key
migration is needed. Badges remain stable when a title is renamed, results are
filtered/reordered, or the same retained import is refreshed. They are not portable
IDs promised to match across separately imported installations.

Captions put the badge before the title, keeping it visible when the existing
bounded menu labels shorten long names. Pending rows retain their owner badge next
to their availability reason. Base-game or unresolved-owner rows do not receive an
invented badge. All UI surfaces call LibraryPackageLabel rather than implementing
separate formatting/hash rules.

Search accepts four to ten hexadecimal badge characters, case-insensitively, in
addition to existing title/source matches. Categories and favorites remain outer
filters. Partial badge searches can match more than one package. Ordinary title
and source searches do not add owner lookups; deliberate badge searches use the
existing per-song identity cache. Visible captions reuse identities already needed
for readiness. There is no new full-library discovery scan on Freeplay entry.
An identity-only cache bounds repeated hashing to 4,096 entries and can be cleared
without changing results. Badges are short visual aids, never ownership proofs.

## Remaining roadmap

Broader viewport/controller acceptance, adversarial labels and user visual review
remain open. Independent group/chart sorting and safe uninstall are still separate
milestones. A future grouped view can reuse the same shared badge in group headers.
This change does not claim menu/import throughput gains or completion of Phase 5.
No publication and no changes to the user's playing installation.
