# Shared selected-stage session checkpoint

Local development v0.0.23, 10 October 2026. This follows the completed source push of the prior checkpoint; these changes have not been pushed or published.

## Implementation

Selected Psych/Nightmare Vision source stages now import transactionally through the state-owned class session already used by ordinary HScript and embedded runHaxeCode. Class descriptors, reflection identity and static storage are shared. The selected runtime retains the session's established native bindings, including owner preferences, and rejects mismatched roots or an additional competing binding policy. Standalone stage runtimes retain their existing independent lifetime.

A scoped construction-policy boundary temporarily installs the selected stage's existing registration and placement service. It restores the previous factories/hooks after success or exceptions without replacing the class registry. Nested source/native stages still belong to the selected construction context; later ordinary script construction uses ordinary insertion. A released scope is not revived by restoration.

Selected runtime cleanup leaves shared descriptors alive until the host finishes its ordered stage callbacks and releases the owner session. Failed imports or constructors preserve pre-existing owner objects, while constructor failure removes that stage's registrations and new scene members. All production changes are in shared engine/compatibility code. No donor edits or chart/mod-specific behavior were added.
