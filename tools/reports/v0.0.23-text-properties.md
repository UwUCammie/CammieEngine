# Shared Psych-family text properties

Local v0.0.23 development. Full-roadmap publication gates remain unchanged.

## Contracts and implementation

Historical source: Nightmare Vision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/data/scripts/FunkinLua.hx`. Current Psych source: `5c67ced49e5a98535298a6daa3f8f4ec79ac8399`, `source/psychlua/TextFunctions.hx` and `source/backend/CoolUtil.hx`.

SourceScriptTextBindings now supplies both dialects' native property writes and getters. It preserves historical void versus Psych boolean setter results, missing getter defaults, default-left alignment and Psych-only justify alignment. Historical borders keep the current border style and write the supplied size after parsing color. Psych borders choose a style, only replace positive sizes, then parse color. Missing-target operations do not evaluate font/color arguments. Psych diagnostics remain visible; historical missing tags remain silent. Field setters preserve the native setter call order rather than swallowing errors.

SourceTextStyle implements distinct historical hexadecimal and Psych named/hex color grammars and shared native border styles. Valid full eight-digit ARGB words preserve all bits on Windows instead of overflowing native strtol. Psych's lowercase 0x prefix still discards the supplied alpha, as in its source utility; #AARRGGBB preserves it. Historical colors retain their raw prefix rule.

The historical adapter installs after general Psych overlays, retaining its dedicated literal text namespace. Psych uses its existing owner-aware target and font resolvers, so nested native text paths are available through the shared callback service. This checkpoint does not claim a full audit of every modern lookup alias, missing intermediate, class coercion or font-path extension. No chart/mod branch or donor edit was added.
