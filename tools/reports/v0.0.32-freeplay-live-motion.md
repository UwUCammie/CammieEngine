# v0.0.32 Freeplay motion and live refresh

The chart browser keeps the selected row's target centered without a direction-based offset. Row position, panel height, title size, icon size and difficulty-grid placement now transition over 180 milliseconds using elapsed time. Retargeting starts from the current geometry, including rapid held navigation. Initial and newly materialized rows begin at meaningful list positions.

Held input retains the 280-millisecond initial delay, 10 charts per second, and 30 per second with Shift. Opposed inputs and blocked browsing reset the repeat timer. Frames contribute at most 100 milliseconds, preventing a long stall from accumulating a repeat burst.

Import generations reconcile the registry inside the existing Freeplay state. Surviving identities retain rows, icons and difficulty stars where their content remains valid. Reordering remaps every parallel table; new and removed identities materialize or dispose only their own components. Metadata and pending candidates are prepared before the live tables change. Source identity, availability and analysis caches are refreshed on the main thread. Selection, named difficulty, search, filters, library settings and native menu music remain in the same browser. Confirmation callbacks are cleared and launch readiness is checked again. An empty refreshed list remains an empty browser; later rows can reappear there.

Pending entries can promote to published entries without borrowing another owner's graphics. Changed character/icon definitions invalidate affected graphics. Rank-rating updates reuse existing stars. Imported preview buffers are invalidated on a registry generation to avoid playing old bytes from a reused audio path; unaffected native preview and menu music are retained.

A refreshed selected song that no longer matches the active filters silently relocates to another matching song. An unchanged matching selection stays selected. This fixes a case where a hidden selection previously left an apparently empty browser despite remaining matches.

HXC module code and owned resources remain snapshots for the current menu lifetime. Live refresh updates association and readiness routing; changed or newly discovered module source applies on the next natural menu entry. This avoids duplicating timers, listeners and graphics through script reexecution. HXC verification is recorded separately in v0.0.32-hxc-freeplay-refresh.md.
