# Shared source member-array checkpoint

Local development v0.0.23, 10 October 2026. No push or publication.

## Implementation

Tracked native group member arrays now use the existing cached native-method boundary for push, unshift, insert, remove, contains, indexOf, lastIndexOf, pop, shift, splice, slice, copy, concat, filter, map, sort, reverse, resize, iterator and keyValueIterator. Insertion and lookup reuse the actual owner's native member conversion. Callback arguments and returned members retain authored source identity. Native array algorithms still control ordering, indexing, mutation and iteration; raw array mutations do not invoke group add transforms or repair the native group's separate length bookkeeping.

Manual array iterators delegate to the original iterator and reject access after caller-scope release. Copying/filtering/splicing methods return ordinary arrays of source objects; map retains the callback's arbitrary return values. Ordinary non-member arrays remain unchanged.

Whole member-array writes to a native FlxTypedGroup preserve the incoming array identity while converting its elements. Conversion is shared by Iris direct/reflected writes, HScript-ex direct/inherited writes and pending native-super fields. Sprite-group members remain their native getter-only view; writes to the internal group retain the sprite element constraint when accessed through that view. Native reflection/property semantics remain in control of assignment.

All changes are shared engine/compatibility behavior. No donor changes or chart/mod-specific branches were added.
