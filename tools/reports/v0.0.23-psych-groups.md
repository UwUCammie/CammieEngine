# Psych group property and mutation contracts

Local v0.0.23 development; the full-roadmap publication gate remains unchanged.

## Source and implementation

Pinned Psych revision `5c67ced49e5a98535298a6daa3f8f4ec79ac8399`: ReflectionFunctions getPropertyFromGroup, setPropertyFromGroup, addToGroup and removeFromGroup, plus their LuaUtils group/path/root helpers.

Modern public bindings now use SourcePsychReflection alongside the existing property/method callbacks. Group roots reuse its source path traversal. Intermediate member fields share SourceScriptReflection.groupFieldOwner with historical NV; the final map/type dispatch remains dialect-specific. The historical profile keeps its existing guarded extension and source adapter.

The modern service preserves the source getter's second literal target-property lookup, array versus native-group dispatch, integer array member keys, raw final field names and optional map access. Setters find the member before parsing values, do not parse absent array members and return the original input. Add/remove operations follow the source active or game-over target and captured object references. Indexed array removal preserves the member; tagged removal destroys when requested even if the object was absent. Native-group removal occurs before destruction and does not depend on the remove method's return value.

No donor edits, chart-name branches or alternate scene renderer were introduced. The native Flixel group and destruction operations remain authoritative.

## Differential coverage

The test extracts the exact pinned callbacks and LuaUtils helpers and compares ordered state/property/registry/parse/diagnostic calls, callback results, destruction events and selected member state. Its 4,864 cases cover arrays, groups, missing and nested roots, variable aliases, maps, literal bracket fields, integer field keys, missing members, game-over roots, root changes during reads, registry changes during conversion/mutation, and tagged/indexed retained/destructive removal. Failure outcomes are compared rather than exact exception strings. This oracle runs on Haxe eval; the native probe checks valid public operations and lifetime with actual Flixel objects.
