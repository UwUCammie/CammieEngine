# Shared source group-member checkpoint

Local development v0.0.23, 10 October 2026. No push or publication.

## Implementation

Source-class group replacement, sprite-group recycling and indexed member writes use the shared owner-aware native conversion service. Captured and reflected group methods retain the authored object identity. Sprite-group recycling delegates to the actual internal native group, preserving Flixel's behavior of omitting preAdd transforms. Replacement retains the native outer method, including applying preAdd before an unsuccessful lookup. Factory-only recycling converts source factory results without changing native availability or capacity behavior.

Reading a native group's members array records its element constraint without replacing the array. Indexed assignments retain that storage and return the original source value; ordinary arrays and map writes remain unchanged. Internal sprite-group member arrays keep the sprite constraint. Iris member and key/value loops, and HScript-ex member loops, restore source identity through the existing shared member adapter, allowing authored fields and methods to be accessed. Source-class owners remain independent across sessions.

All production changes are engine/compatibility changes. No chart-specific or mod-specific branches or donor edits were added.
