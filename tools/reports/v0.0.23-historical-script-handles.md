# Historical HScript handle calls and stop

Development v0.0.23, local only. This checkpoint preserves source-version behavior inside the existing module and interpreter. It adds no chart/mod branches and changes no donor content.

## Source contract

Pinned Nightmare Vision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/data/scripts/FunkinHScript.hx`: call, executeFunc, stop, get, set and exists.

Historical call invokes executeFunc with the script handle as receiver, returns raw callback values, and converts null to Function_Continue. Missing and non-function callbacks also return Continue. Receiver/extra variables are restored through the source map algorithm, including restoring previously absent keys as null entries. Nested direct calls use that same receiver. The source clears interpreter variables and nulls the interpreter on stop without emitting onDestroy; repeated stop is allowed, while later get/set/exists/call access fails.

## Shared implementation

The production gameplay seeder selects historicalCalls on the existing NightmareVisionScriptModule before execution. Both public call and internal value dispatch use the existing executeFunc implementation for that profile. Modern public calls continue returning Iris result records. stop shares native module/interpreter release, including resource cleanup and clearing retained globals. Stopped historical access reports the script name rather than silently behaving like a live missing callback.

## Evidence and limits

The executable source comparison and real Iris tests cover raw scalar/array/object returns, missing/void/non-function callbacks, nested receiver identity, receiver restoration after callback errors, temporary variable maps, saved/reflected method calls, shared registry dispatch, repeated stop and post-stop access. Existing modern public module tests cover result-record behavior and isolation.

Full historical constructors, parser differences, scriptTrace diagnostics, Lua public handles/loading, writable event/type maps, arbitrary source-created registration, callback-driven teardown and generic lifecycle routing remain open. Gameplay profile selection does not certify persistent scripts constructed outside gameplay. No full authored-scene compatibility claim follows from these bounded tests.
