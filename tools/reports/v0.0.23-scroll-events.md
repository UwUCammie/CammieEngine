# Historical Change Scroll Speed event

Local v0.0.23 development. The full-roadmap publication gate remains in force.

## Source and shared implementation

Historical Nightmare Vision source: `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx`, Change Scroll Speed and the opening of generateSong. Modern duration comparison: `733165c42ca71eb0961a70e4173b2d81ba4a29ea`, `source/funkin/states/PlayState.hx`.

Historical generation reads scrolltype and stores chart speed. Its commented-out preference multiplication is not applied at generation. The speed event subsequently multiplies chart speed, the live scrollspeed preference and the parsed event multiplier. Invalid multiplier/duration strings default to 1/0. Nonpositive durations write through the shared songSpeed setter; positive durations use the existing native tween owner with linear easing and historical seconds.

Constant mode returns from the whole historical event, suppressing its post-effect script notifications. Suppression is per dispatch call, so nested events cannot leak suppression into their caller. Native host callbacks retain their existing place in the pipeline. Other dialects retain their existing dispatch path.

Public songSpeedType and songSpeedTween are live state fields. New speed tweens do not cancel previous ones. The completion of an older tween clears the currently published handle, as the historical source does, while the newer native tween continues. The existing owner handles pause/resume and teardown of its still-managed event tweens, preserving unrelated native tweens. This extends the existing camera/HUD tween owner rather than introducing another manager.

No chart/mod-specific production branch, donor change or copied scrolling subsystem was added.

## Limits and next work

Modern NV divides authored tween duration by playbackRate. This checkpoint preserves the historical revision's unscaled duration; it does not claim to complete modern NV/Psych speed generation, setters and event parity. Consolidate the matching event semantics as those profile contracts are audited.

The source globally pauses timers/tweens; the current host event owner only manages its own event handles. Full global lifecycle behavior, arbitrary script-created tween ownership and authored speed-event scenes remain open. Native checks use a disposable manager, generatedMusic disabled during the speed-event transactions, and synthetic observers; real sustain resizing is covered separately by the preceding speed-storage checkpoint.

Next implement historical Set Property traversal/raw values, then continue the explicit initialization, null-GF, Lua/lifecycle, source-class and authored-scene gaps. All imported-menu, library/freeplay, sorting and fidelity-preserving performance goals remain unchanged. Nothing was pushed or published.
