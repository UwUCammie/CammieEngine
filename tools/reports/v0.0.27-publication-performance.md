# v0.0.27 importer publication path preparation

The next non-chart checkpoint replaces repeated linear duplicate searches in the shared import publication path with exact-string lookup tables. It changes no chart, mod, asset, format, transaction or readiness policy.

The copied masked list retains its original order and duplicates. Output paths append in first-seen order. Reservation paths still use the same normalization, case-sensitive spelling and final sort. Owner expansion runs before the lock; readiness revisions change only when the published reservation changes. Cancellation/cooperation checks remain per output and now also cover construction of the masked-path lookup table.
