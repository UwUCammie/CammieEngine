# Psych live stage context checkpoint

10 October 2026, local v0.0.23. No push, tag or release.

Stage helpers now distinguish the current state, the published PlayState instance and PlayState statics through a shared SourceStageContext supplied by PsychObjectProviders. Asset resolution and source-class ownership remain scoped to the imported owner. Production compiled-stage creation uses these providers; detached fixtures retain their explicit host.

Scene operations, actor/camera fields and variables follow the active state. Gameplay helpers are gated by native PlayState identity and use the published gameplay instance. Story/cutscene values stay available outside gameplay. getStageObject uses the existing shared typed map reader rather than a host method fallback. Source string song names are preserved, while native HUD objects still use the established chart-path formatter. Default GF assignment fills both missing and empty values; zoom assignment returns its readback value.

Fallback actor-group views are cached per state, so retained views do not retarget their actors and returning to a state preserves identity. Source constructor registration follows the active state while keeping its original class scope. Failed construction removes registrations from the exact arrays used and cleans newly added members from the initial creation state.
