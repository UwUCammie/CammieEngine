# Historical public splash ownership and hit timing

Local v0.0.23, 9 October 2026. Publication remains withheld until the roadmap exit gates pass.

## Source and implementation

Pinned source: NV `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx` (global group creation, `spawnNoteSplashOnNote`, `spawnNoteSplash`, `goodNoteHit`, `popUpScore`) and `source/gameObjects/Note.hx` (rating defaults and scalar modifier).

Historical gameplay now uses the native state's global splash group, with one source seed and one update/draw owner. Per-field teardown does not own or destroy that group. Historical field initialization does not create modern sustain covers; modern field skin/motion passes do not alter the global historical pool. Modern NV retains its field-owned pools and gates.

The source public note entry checks only the historical owner `noteSplashes` preference, a non-null note and its live receptor. The coordinate entry does not apply that preference or modern field/hazard/sustain/skin gates. It selects noteskin offsets and quant texture before reading the mutable global group, recycles only the historical source class, establishes membership before the source callback, and ignores the callback return as the source does. A null note on the coordinate API fails explicitly at the source dereference boundary rather than risking a native null access. Source song-name exceptions remain excluded, with generic authored replacements still required.

Historical normal-hit scoring/splashes occur before health, singer animation and hit callbacks; historical hazard splashes follow miss handling and honor disabled/sustain gates. Modern rating/splash order remains unchanged. Historical notes use the source `unknown` default, a string rating and independently writable numeric modifier; modern notes retain their rating descriptor and read-only modifier view. The historical splash preference is owner-persisted, seeded from the equivalent native option without modifying native settings.

## Remaining scope

This checkpoint does not certify full historical hit/cancellation, scoring or callback parity. The common hit dispatcher still includes modern admission and note-type callback structure outside this splash package. Source-created/recycled note lifetimes, mutable callback generation timing, wider keys, source songSpeed behavior and all other Phase 2 gates remain open. Native quant texture and seven-key raster checks, full authored scenes, advanced Animate and embedded/custom library APIs remain required. Later menus, library management, categories/favorites, dense Freeplay, icon/star correctness, independent sorting and fidelity-preserving performance goals are unchanged.
