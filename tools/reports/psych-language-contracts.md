# Psych Language contracts

`PsychLanguageRuntime` ports the callback-facing Psych 1.0.4 Language service for one captured imported owner. It was compared against donor `fnf_sources/FNF-PsychEngine` at commit `5c67ced49e5a98535298a6daa3f8f4ec79ac8399`, `source/backend/Language.hx`, Git blob `02f03ffd2262c5fd9c9fdbd8b703deb95d816391`.

`reloadPhrases` asks its required host callback for the selected owner's already-merged source lines, then applies the donor parser in order: clear the current map; use a first line without `:` as `language_name`; skip short and `//` lines; parse the key before `:` and the text between quotes; replace literal `\\n` with newline; and let later rows overwrite a duplicate key. If no phrase row was accepted, only the captured owner preference is reset to `defaultData.language`. It then resolves `images/alphabet`, removes an `images/` prefix and the first `.png` suffix, and calls the captured alphabet-data loader. The runtime does not select paths, enumerate mods, touch `ClientPrefs` globals, or call process-global `AlphaCharacter` state itself.

`getPhrase` preserves donor key formatting, fallback order, and numbered replacement. Missing translations use `defaultPhrase`, then the original key. `getFileTranslation` uses a trimmed lowercase key and returns the input unchanged on a miss. The mutable `defaultLangName` and `phrases` fields plus `reloadPhrases`, `getPhrase`, and `getFileTranslation` are available through the real `Language` class token under both `Language` and `backend.Language`. `PsychLanguageBindings.installLua` registers the two donor callback names and delegates to that same runtime. HScript and Lua method handles check owner liveness on every call, including handles captured before release.

The host contract is intentionally narrow: `ownerActive`, `mergedLines(language)`, `loadAlphabetData(path)`, and `report`. `mergedLines` must return authenticated source text in the caller's established order. Its completeness is an integration responsibility and is not certified by these files. This implementation does not reproduce the donor's wider `Mods.mergeAllTextsNamed` discovery order; that needs the engine's authorized source registry. The runtime does not reload merely because a callback is invoked. The caller must invoke `reloadPhrases` at the same lifecycle points as its source Language integration. `getPhrase` preserves the donor's direct `String.replace` call for `Array<Dynamic>` values rather than adding a new numeric conversion rule.

Focused verification is in `tools/tests/test_psych_language_runtime.py` and `tools/tests/test_psych_language_bindings.py`. These execute the parser, fallback and interpolation paths, ordered override behavior, empty-table preference reset, alphabet callback path, owner isolation, real HScript class token/reflection, Lua callback names, reflection composition, and retained-handle guards. Both tests passed with the portable Haxe interpreter. No game build, full suite, or native launch was run for this contract.
