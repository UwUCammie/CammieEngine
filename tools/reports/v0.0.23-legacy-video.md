# Historical Nightmare Vision video checkpoint

Development version: v0.0.23. Release v0.0.22 is already published; this work is not included in that artifact.

## Work package and source contract

The retained historical package reached `new PsychVideoSprite()` and failed before its opening video could load. Implement the historical API at the compatibility boundary using the existing video renderer, decoder, owner path resolver and state lifecycle.

Authoritative local Nightmare Vision source: commit `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/PsychVideoSprite.hx`.

| Source interface | Implementation |
| --- | --- |
| `new(destroyOnUse = true)` | Boolean constructor over the shared video sprite at (0, 0). End destruction listener is installed at construction, matching the source even if the public flag changes later. |
| `load(location, options)` | Shared selected-owner resolution and pinned hxvlc decoder. Retain the requested path only on successful load. |
| `addCallback(name, callback)` | `onEnd`, `onStart`, `onFormat` attach to decoder end, opening and format signals. Unknown names/null callbacks do nothing, as in the source. No synthesized late callback or error completion. |
| `restart(options)` | Reload the last accepted path with caller options and play. |
| `looping`, `muted` | Shared source option strings. |
| `pause`, `resume` | Shared decoder methods, with the historical explicit-pause focus behavior mapped to pinned hxvlc focus handlers. |
| `heldVideos`, `globalPause`, `globalResume` | Live source registry and methods scoped to the calling script's mod and state, including reflected access. |
| `initializeSkip()` | Empty in this historical source; preserved as such. |
| `VidCallbacks` | Source string constants through qualified and bare imports. |

The modern `funkin.video.FunkinVideoSprite` constructor is different and retains its existing binding. Reusable shared sprites reset format/completion state for each accepted new path. The legacy adapter shares the existing `pauseForState`, `resumeForState` and `destroyForState` host integration; it adds no second lifecycle dispatch.

Private constructor leases opt into replacement/unbind cleanup. Other factories retain their existing shared-owner behavior. An interpreter reinstall cannot accumulate retained empty video registries.

## Scope and remaining work

This is a historical video adapter checkpoint, not full chart or Phase 2 acceptance. Real clip loading, rendering, end dispatch and gameplay handoff are verified at both caps. Pause/resume, restart and teardown have controlled production-adapter tests, but do not yet have a dedicated real-decoder lifecycle probe; that validation remains open. Advanced Animate APIs, embedded/custom asset-library contracts and the remaining scripting surface stay open. All imported menu, mod-management, categories/favorites, dense Freeplay, icon/star, independent sorting and fidelity-preserving performance requirements remain in the roadmap.
