# Historical Lua property callbacks

Local v0.0.23 development. Publication is still gated on completion of the full roadmap.

## Source and implementation

Pinned historical Nightmare Vision source: `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/data/scripts/FunkinLua.hx`. The source callbacks use getVarInArray/setVarInArray for the final token, unlike the literal final field of the Set Property chart event. Successful Lua setters return true. Root-only calls use the active gameplay/game-over instance and do not resolve sprite/text tags first; nested paths do resolve source tags before the current instance.

The shared reflection service now provides this policy and shares intermediate traversal with the event path. It preserves exact paths, raw values and key handling, dynamic array writes, getter mutation, and propagated failures. Only historical Lua scopes receive these bindings. Native host calls, modern/Psych scopes, HScript extension bindings and the results observer retain their current routes.

Source playerStrums/opponentStrums and the fresh flattened strumLineNotes array now resolve through the existing historical receptor references for Lua/event reflection and HScript alike. Shared reference writes do not overwrite host receptor groups. The shared source HUD adapters remain in use. No chart-specific production branch or donor edit was introduced.

## Evidence and limits

The differential fixture extracts both Lua callbacks and their helpers from the pinned source. It compares 480 read/write/read sequences across live/dead state, getter-triggered mutation, raw value types, missing/null tags, exact paths, map fields and nested/final array indexing. Profile isolation covers ordinary interpreters, nonhistorical Lua and the results observer. The 1,232 existing event comparisons remain passing. The real Iris receptor test additionally checks shared writes and fresh array order.

Initial harness failures were caused by extracting an expression-bodied method through its following method, mixed-value Haxe fixture typing, and snapshot reads after deliberate root replacement. These were corrected, retaining the original behavioral assertions and adding type-sensitive results.

This does not complete group/class Lua callbacks, all source-visible aliases, text creation/game-over mounting, initial actor loading/null GF, ghost APIs, global timer/tween lifetime or authored-scene acceptance. Native component probes are synthetic checks within a disposable runtime, not full-chart fidelity certification. Modern/Psych scroll parity and all later menu, library, dense Freeplay, sorting and quality-preserving performance goals remain open.
