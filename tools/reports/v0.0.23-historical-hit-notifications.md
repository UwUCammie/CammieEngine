# Historical NV hit notifications

Local v0.0.23 development; no publication.

## Source contract

Compared with Nightmare Vision revision 7f96eb3b5a60352413229bf134bd348b79ad5fe6, source/meta/states/PlayState.hx goodNoteHit, opponentNoteHit and callOnScripts. Historical hits notify global Lua with five scalars (group slot, absolute lane, authored type, sustain flag, note ID), then global HScript with the live Note, then the current attached type script. Family return values do not cancel the following family or native completion. A global callback can replace or clear noteScript before its attached callback runs. Historical callbacks do not receive a modern Pre or generic type-hit notification.

## Shared implementation

The common NV broadcaster now handles both modern Int-only and historical arbitrary-value returns, retaining preceding values on HALT. ScriptGroup still owns the module invocation and lifetime. Historical global HScript hit dispatch checks live note/event registry names per callback. It reuses existing loaded modules rather than cloning scripts. The note runtime prepares the source argument arrays once, reads the attached script only after globals, and shares its existing execution and synchronization path.

Active Lua scopes use the existing Psych scope discovery and invocation, with historical return flow and the already-prepared five arguments. Type/event compatibility scopes are omitted. Later base observer broadcasts skip already-notified Lua scopes for these historical note-hit callbacks while retaining host HScript observers, preventing the previous second Lua notification. Modern NV keeps its current Pre/type-hit ordering and return behavior.

## Remaining scope

This does not finish the historical default hit handlers. Default callback identity still needs to be fixed independently of mutable field flags, along with distinct opponent/player flags, singer/ghost gates, health/scoring completion, receptor confirmation order and wider-key admission. Lua attachment/loading and historical source arrays/maps remain incomplete; the Lua bridge here covers scopes already loaded by the shared runtime. General historical lifecycle broadcasts and type/event update scheduling still need source filtering and ordering beyond these hit notifications. Synthetic native probes do not certify full authored-chart or source Lua interpreter parity. Keep all remaining roadmap goals and release gates open.
