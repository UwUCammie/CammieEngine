# v0.0.28 installed ownership and Freeplay checkpoint

12 October 2026. Engine/importer and host-menu changes only; donor files and the playing installation are untouched.

## Installed ownership

`ImportInstalledOwnership` joins live provenance, compatibility roots, package markers, menu catalog roots and the global results provider to the strict retained inventory. Unclaimed owners, missing claimed metadata, engine mismatches, changed receipt-backed metadata and undeclared cross-transaction dependencies block assessment. The result is detached and read-only. Host-owned providers use an explicit engine-owned root allowlist.

`ImportMetadataInspection` shares path validation, bounded streaming reads, cancellation, byte/entry budgets and final metadata change detection between retained and installed audits. These are advisory snapshots, not execution reservations.

Executable tests cover 16 retained inventory scenarios and 15 installed ownership scenarios, including valid commits, missing/edited metadata, unknown owners, invalid engines, protected providers and cancellation. Existing removal-plan contracts remain covered. Native generated-package checks passed at 60 and unlimited FPS with installed ownership, receipt preservation and moved/repeated source identity checks.

Uninstall remains unavailable. Per-package ownership splitting for aggregate imports, identity/history archiving and reinstall restoration, reservations, live-byte revalidation, registry reconciliation, recoverable execution and cleanup still require implementation and acceptance. This does not establish ownership of every loose file inside an installed root.

## Host Freeplay

Favorites always precede ordinary songs and the Random action. Existing group/chart ordering applies independently within favorites and ordinary songs; imported custom menus retain their source behavior. Favorite save transactions invalidate the cached order in every sorting mode.

Unselected rows are 42 logical pixels tall and the selected row is 82. At 720p, eleven rows fit above the footer. Only the selected row shows source metadata and a larger portrait; disabled rows retain their tint and selection details explain the import lock. Favorite badges, cream/pink/teal accents, an angled title and twelve elapsed-time animated meter bars add emphasis without per-frame graphic creation. Row virtualization, difficulty/completion controls, filters and selection identity remain shared.

Layout tests cover 480/720/1080 logical heights, paging boundaries, filtered indexes, expanded-row space and footer separation. Sorting tests cover pinning across grouping/order modes and cache invalidation after removing a favorite. Muted private-desktop native navigation passed favorites, categories, independent sorting, confirmation, difficulty persistence, gameplay return and refresh continuity. Captures were inspected for row, icon and text alignment. Physical-controller review, broader viewport detail-panel refinement and the remaining original roadmap goals are still open.
