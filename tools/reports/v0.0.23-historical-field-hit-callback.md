# Historical NV field hit callback checkpoint

Local v0.0.23 development. Nothing in this checkpoint authorizes publication.

## Source contract and change

Compared against Nightmare Vision commit `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/PlayField.hx` and `source/meta/states/PlayState.hx`.

Historical fields expose an assignable `noteHitCallback(note, field)`. Default callbacks are installed before `preReceptorGeneration`; a script-created or replacement field starts without a callback. Input invokes the selected callback instead of a modern signal. A replacement therefore controls whether scoring, animation and note retirement happen at all.

The existing field adapter now exposes that callback and routes historical input through it. Lifecycle rebinding and publication preserve script assignments. Null callbacks produce an attributable compatibility error; throwing callbacks retain their error and restore the surrounding hit context. Field destruction releases callback references. Modern NV continues to use its existing ordered signal listeners.

Automatic admission now uses a shared field predicate. Historical tap notes wait for their timestamp, while sustain segments use `canBeHit`. Modern NV retains its timestamp predicate. Both source field queries and automatic admission read the native computed hit window with property-aware access, avoiding the hxcpp dynamic-field path that bypasses getter-only storage. Historical manual callbacks cannot bypass the hit window through the host hold shortcut.

All production changes are in shared engine/compatibility code. No imported chart, script, asset or song-name exception was changed.

## Remaining work

This checkpoint does not certify complete historical hit behavior. Default callbacks still bridge to the common handler, whose selection of good/opponent/extra family from mutable field flags differs from the historical fixed callback identity. Public default-handler signatures, attached `noteScript` ownership, global/type callback arguments and ordering (including exclusion of event/note-type registries from general broadcasts), absence of modern Pre/type-hit callbacks, callback-return semantics, player/opponent hit flags, source singer/ghost gates, health/scoring completion and wider-key manual sustains remain open. These source-derived gaps now appear explicitly in the roadmap.

The native probe replaces callbacks synthetically over retained owner gameplay. It is an integration check, not full authored-scene acceptance. Later menu, mod management, Freeplay and performance goals remain unchanged.
