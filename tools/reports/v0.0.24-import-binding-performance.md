# Shared import asset-binding indexing

Local v0.0.24, 10 October 2026. Engine/importer changes only, with no authored chart, shader, media or donor changes.

## Change

`ImportRefreshManager.buildAssetIndexBindings` previously validated and normalized every committed file separately for every root. It now validates each entry once and routes it to roots by complete path components. Local indexes last for one call only. This preserves exact case, nested roots, sibling prefix boundaries, file order, duplicate entries and last-valid-sidecar precedence. Receipt identity, SHA format, ownership, profile ambiguity and authenticated family handoff rules are unchanged.

It loads the same committed 24,702-file, 23-root manifest and alternates execution order over four pairs. Scheduler cooperation is stubbed; family validation returns the already validated catalog. The measurement isolates binding construction, excluding manifest parsing, forced pre-run GC, canonical serialization and output hashing. No builds, tests or unrelated hash workloads overlap timing.

## Validation

The focused binding regression passes. It checks nested/sibling roots, duplicate root and file entries, wrong ownership/case, invalid SHA and rejected normalized paths, per-call freshness, immutable prior output, sidecar precedence, profile ambiguity and NV family handoff rejection. It also verifies normalization occurs once per eligible entry rather than per root.
