# Shared source group-query checkpoint

Local development v0.0.23, 10 October 2026. No push or publication.

## Implementation

Native group availability and recycling now share one matcher for authored source descriptors and native classes. Source-backed FlxObject members are recognized through their actual native superclass instead of the storage bridge's FlxBasic type. Exact native-class filters exclude authored subclasses, source-class filters preserve descriptor ownership and inheritance, and null/exact filtering keeps the pinned native behavior. Availability reads current native member state, so a direct source kill is visible before a bridge update. Positive-capacity recycling still delegates rotation to Flixel; factories retain their actual ownership and are checked after callbacks.

Captured and reflected group methods now adapt first/last predicates, indices, any/every, typed callbacks, sorting, random/member results and manual group iterators. Existing/existing-and-alive/dead lookups read the composed native member state. Native getFirst, forEach, sorting and iterator implementations retain traversal and mutation behavior. Array and group iterators share one identity/lifetime adapter. Ordinary and source class requests use the same paths across Iris and HScript-ex.

Production changes are shared engine/compatibility changes. No chart/mod-specific branches or donor edits were added.
