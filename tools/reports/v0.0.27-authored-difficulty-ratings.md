# v0.0.27 authored difficulty ratings

12 October 2026. Shared importer and host-menu metadata; donor content is unchanged.

## Contract

V-Slice's source `SongPlayData.ratings` maps difficulty IDs to authored integer
ratings. Its converter now retains the complete named table with a V-Slice scale
label. Import registration carries that validated descriptor table into the
Freeplay registry; host rows retain it without opening chart files while browsing.
The selected details panel resolves by difficulty name, independently from the
host registry order, and refreshes when selection/difficulty/filter state changes.

Authored zero is a value. Missing, negative, non-finite, string/boolean values and
ambiguous case-colliding names do not become ratings. Unknowns say Unknown.
Descriptor reads copy the data, preserving donor immutability. Completion stars
and favorites remain separate; numeric V-Slice ratings are not converted into an
invented five-star scale.

Existing FPS Plus `difficultyRatings` arrays remain intact. Those arrays do not
record a proven source difficulty-name order in the Freeplay registry, so this
checkpoint deliberately does not map them using the host's configurable order.
Source-profile/name-order recovery for those older arrays remains a compatibility
and importer task. Existing imports need a normal regeneration to acquire the new
V-Slice metadata. Its engine-specific importer revision advances from 2 to 3,
so retained V-Slice sources are scheduled through the normal safe refresh path.
Common and all other engine revisions remain unchanged; this does not force a
full-library reimport or parse large charts on each selection. Other engines without declared rating metadata
remain unknown.

## Validation

The focused compiled test passes actual VSliceImporter conversion, registry-export
helper behavior, named/custom/zero/absent/invalid/ambiguous lookup, source scale and
donor immutability (`tmp/v27-ratings-focused.log`). The expanded mixed-import
fixture passes actual registry writes for base and alternate V-Slice variations,
with distinct named ratings and their source scale
(`tmp/v27-ratings-mixed-recheck.log`). The importer revision test passes the
V-Slice-only retained-source refresh contract (`tmp/v27-ratings-revision-test.log`).

Canonical `run.bat test` built Windows and ran 2,790 tests across 939 modules in
406.4 seconds, with 344 skips and one failing module
(`tmp/v27-ratings-full-test.log`). That failure was the mixed-import standalone
fixture not copying the new shared helper. The fixture was corrected and its
expanded rerun passed. The full suite was not repeated after that fixture repair.

Muted native checks on a never-activated private desktop passed at configured
60 and unlimited FPS (`tmp/v27-ratings-native60.log` and
`tmp/v27-ratings-nativeuncapped.log`). These exercise an explicitly synthetic,
in-memory named rating table, difficulty changes, Favorites/category/empty views,
and a gameplay roundtrip that restores the real registry's Unknown rating. They
do not claim a native donor-import rating test. Actual donor-shaped conversion
and registry publication are covered by the compiled fixtures above. Captures
`tmp/compatibility-visual-check/tmp/v27-library-rating60.jsonl.navigation-favorites.png`
and `.navigation-returned.png` were inspected for label placement and separation
from completion stars. Functional checks overlapped background work and are not
FPS or menu-performance benchmarks.

The final Windows rebuild passed with the scoped revision change
(`tmp/v27-ratings-final-build.log`). No playing-install or ordinary save
changes, donor edits or publication.
