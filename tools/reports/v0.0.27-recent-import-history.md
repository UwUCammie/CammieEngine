# v0.0.27 recent-import library order

12 October 2026. Shared importer publication and host library UI; no chart/mod changes.

## Behavior

Recently imported is a group-order choice, independent of mod/engine grouping and
chart order. Successful manual imports record only the transaction's published
record roots, after the main-thread difficulty/cache handoff has completed and
availability reservations have been released. The observer runs outside the
coordinator mutex. Broad dependency/readiness locks do not count as new imports.
Parent-folder selections that skip authenticated unchanged installations record
only newly committed roots. Automatic refresh, no-op manual imports, failed
conversion, deferred gameplay handoffs and incomplete/failed batches do not
update history. Repeated completion calls cannot record a released reservation.
A manual re-import that actually commits may become recent again.

The existing host library save gains optional import history. Shared
LibraryHistoryData validates and serializes both play and import chronology,
while package batches intentionally share one timestamp and sequence. Timestamps
are observed completion times; ordering uses an exact monotonic sequence so clock
rollback and tied times do not reorder newer imports behind older ones. Unknown
legacy history remains unknown, with no filesystem-date inference. Malformed
history is rejected without overwriting the existing save. A failed history save
preserves the prior model/disk data and cannot invalidate installed content.

Mod groups order by their observed sequence; engine groups use the newest
contained mod. Simultaneous batches use stable group identities for ties. Groups
with unknown history follow known history. Chart sorting remains local and
independent. Flat lists ignore group order. Browser ordering uses the existing
cache and invalidates on a published library transaction, without repeat metadata
reads during unchanged navigation. Original launch/readiness indexes remain intact.

## Scope and remaining work

No importer revision bump or forced re-import is needed. Existing unknown history
stays unknown. A crash between publication and successful history observation can
leave that import's chronology unknown; this is not a durable transaction journal
or a reconstructed installation date. Crash recovery, fresh-process UI/reinstall
acceptance and physical controller review remain broader roadmap gates.

Next add comparable score/rating orders where real metadata supports them, and
verify explicit donor week/freeplay ordering. Safe uninstall, additional viewport
and imported-menu acceptance, matched import/menu performance measurements and
all original gameplay/GPU compatibility goals remain open. Nothing was published
and the separate playing installation was not changed.
