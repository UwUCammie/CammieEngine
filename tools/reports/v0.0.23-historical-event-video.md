## Source contract and implementation

Pinned Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx` (`eventPushed` and `playVideo`) and `source/gameObjects/shader/GreenScreenShader.hx`.

Public `eventPushed` and normal event generation use the same preparation service. Builtins own their preparation without an additional custom `onPush`; other handlers retain scalar Lua arguments or the mutable HScript event object. Public calls prepare the supplied object without inserting it into the event queue. Bare, instance, class and reflective historical HScript access reuse the live binding service.

Historical Play Video preparation starts a hidden instance; firing the event starts a visible instance. Both use the existing owner-scoped decoder and sprite lifetime services. The small source adapter preserves callback registration, load/play/add ordering, deferred HUD camera assignment, zero scroll factor, height-only fitting and end destruction. The pinned chroma-key shader is exposed through source imports and reflective class lookup. Modern NV and generic native event-video handling retain their existing paths.

There are no donor edits or chart/mod-specific production conditions. This adapter does not introduce a second video decoder, asset resolver or script runtime.
