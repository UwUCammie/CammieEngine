# Psych note callback native contracts

This bounded development 0.0.16 correction preserves the mixed Lua callback payload and callback return types on Windows C++. It applies to the shared successful-hit and miss callback helper, without content-specific branches or authored chart/script edits.

## Source contract and observed defect

The retained Psych source at `../fnf_sources/FNF-PsychEngine/source/states/PlayState.hx` calls Lua successful-hit callbacks with the live note group index, normalized direction, String noteType, and Bool isSustainNote. HScript receives the same live Note object after the Lua family, subject to Function_Stop, Function_StopHScript and Function_StopAll. Function_StopLua does not suppress HScript. `test_psych_note_callbacks.py` retains executable helper assertions and the donor's stage/Lua/HScript/retirement ordering comparison.

The private Shadow Wizard diagnostic observed source timing mode 1 and an active source ledger, but its real native Lua opponentNoteHit arguments contained integer zero for the authored note-type String and integers zero/one for the sustain Bool. Lua treats zero as true, so the script skipped ordinary heads and its speaker-name cases did not match. Actual generated `export/release/windows/obj/src/PsychNoteCallbacks.cpp` confirmed an `Array_obj<int>::__new(4)` payload and a String-narrowed broadcast result. Eval-only callback tests had not exposed this native inference defect.

Separate initial subtitle diagnostic failures were fixture errors: Windows Std.parseInt of unsigned `0xFF...` saturated at 2147483647, while the actual rendered subtitle ARGB values were correct. The private probe now compares RGB channels against a six-digit parsed value and asserts sprite alpha independently. This callback correction does not change Std, icon rendering or subtitle color policy.

## Implementation and verification

`source/PsychNoteCallbacks.hx` now declares preparedLuaArgs as Array<Dynamic>, begins the new literal with a Dynamic group-index cast, and declares the broadcast result Dynamic. Supplied pre-hook argument arrays retain their original identity. The existing Lua-family stop decisions and live-Note HScript dispatch remain intact. `PsychMissCallbacks` delegates to this same helper; its missing-note noteMissPress payload intentionally contains only the direction.

The focused command `python -m unittest test_psych_note_callbacks test_psych_script_broadcast -q`, with `PYTHONPATH=tools/tests`, passed all five cases in 0.424 seconds without skips or failures. Added checks cover String noteType, true and false Bool sustain values, and numeric, Bool and object result type/identity alongside existing sentinel cases. The C++ export test uses `-cpp ... -D no-compilation`, positively asserts `::cpp::VirtualArray_obj::__new(4)` and a Dynamic result, and rejects the observed integer-array/String-result form. It generates native source; it does not claim a standalone compiled C++ execution.

Review of adjacent call sites found that `EngineCompat.psychNoteCallbackArguments` already emits a VirtualArray containing all four source argument types, and `PsychScriptBroadcast` explicitly declares individual sentinel-compared callback values Dynamic. A separate exact generated-code finding in PlayState.dispatchPsychNoteHitPre narrowed its local dispatch result to String. After root authorization, that local alone received the same explicit Dynamic annotation. Its payload remains unchanged. The existing extracted pre-hit lifecycle fixture now also exports C++ and rejects String result declaration/casts in the actual extracted method. The focused source_gameplay_lifecycle plus psych_note_callbacks batch passed ten cases in 0.576 seconds without skips or failures, retaining the original sentinel, lane, spawn and lifecycle assertions.
