## Implementation and source contract

The shared native adapter generator now forwards FlxSpriteGroup.initGroup and FlxSprite.graphicLoaded to source overrides, including inherited overrides and explicit native super calls. Sprite, text and sprite-group classes use the same graphic callback and lifetime service. The sprite-group capability enables only the initialization hook actually supported by that native base.

Pinned Flixel 6.1.2 constructs group storage through initGroup before calling its sprite superclass. Its frames setter notifies graphicLoaded after installing frame/graphic state; clearing frames does not notify it. The implementation retains those native algorithms. It does not duplicate group storage, bitmap loading, frame selection or resource reference counts. No chart/mod-specific branches or donor edits were added.

The pinned Psych objects/Note.hx and NV funkin/objects/note/Note.hx set_clipRect overrides assign clipRect directly inside its own setter; simply forwarding that method through the existing Reflect.setProperty path would recurse.
