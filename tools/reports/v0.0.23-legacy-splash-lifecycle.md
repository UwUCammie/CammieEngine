# Historical splash setup and noteskin callbacks

Local v0.0.23, 9 October 2026. No publication.

## Contract and implementation

Pinned NV source: `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/NoteSplash.hx`, `StrumNote.get_swagWidth`, and `source/meta/states/PlayState.hx:spawnNoteSplash`.

The historical `gameObjects.NoteSplash` identity now constructs a native splash with source `(x, y, note)` arguments. Bare `NoteSplash` selects the historical identity for the historical owner profile, while the explicit modern class retains its receptor/RGB contract. Direct and reflected constructors use the existing owner factory and shared sprite, animation, shader and pool services. The historical adapter adds no separate renderer.

Historical construction loads the song/default splash atlas, binds HSL, performs coordinate setup and then applies the owner's antialiasing preference. Setup takes `(x, y, note, texture, hue, saturation, brightness, field)`, uses each receptor's live parent spacing, multiplies retained scale when a field is supplied, selects source animation variants and random rates, and retains the source pre-parent-update retirement boundary. Direct `loadAnims` selects historical aliases. The pinned source never assigns `textureLoaded`; repeated setups therefore reload even for the same texture. Missing animations produce an attributable error rather than silently becoming an inert effect. Modern setup remains covered by the unchanged donor comparisons.

The live historical field-spawn path calls noteskin `noteSplash(offsets)` then `quants()` before recycling. Fresh per-key offsets, quant-prefix selection and note/default HSV inputs feed HSL setup. Membership is established before the historical `spawnNoteSplash(splash, lane, note, isPlayer, lazerSplash)` notification; modern NV keeps `onSpawnNoteSplash(splash, note)`. Native receptor `parent` and `swagWidth` expose the source field spacing used by setup.

No donor, chart or retained mod was modified. No source song-name exception was copied into the engine.

## Remaining acceptance

This implements the historical class and connects its normal field-spawn path; it does not complete historical PlayState splash parity. Public `spawnNoteSplash`/`spawnNoteSplashOnNote` entrypoints, the source global group identity, exact historical hit/public-spawn gating, cancellation and lifecycle membership must be compared as the next connected package. The host still stores splashes in owned field pools. Source hardcoded song exceptions need general authored-data/script equivalents if they are to be supported, never name branches.

The native probe uses generated source calls and temporary noteskin hooks over an actual retained atlas. Its frozen sprites establish constructor/frame/HSL rendering. It does not certify a full authored splash sequence, quant texture raster, seven-key native scene, historical shader replacement or every inherited FlxSprite API. All other Phase 2 and later menu, management, Freeplay and performance requirements remain open.
