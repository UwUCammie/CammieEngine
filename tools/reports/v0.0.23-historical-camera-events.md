## Source and implementation

Pinned Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx`, triggerEventNote and the public camTween/camHUDAlphaTween fields.

The outer shared dispatcher retains post-effect script notification. This is engine-version behavior, with no chart/mod branches or donor edits.

Camera Zoom preserves the source multiplier, empty-duration behavior, fixed circOut easing and HScript-only defaultCamZoom publication. Add Camera Zoom preserves the preference and 1.35 guard. HUD Fade shares parsing and direct assignment with the existing host helper while supplying historical handle-specific cancellation and native tween creation. Follow position shares the existing host helper. Flash, shake and actor offsets use the existing camera/offset services with historical arguments.

The public native handles use existing script/reflection access. The adapter tracks its own created tweens independently of writable public handles, pauses/resumes only its still-managed unfinished tweens and cancels them on owner teardown. Replacing a source fade leaves unrelated tweens intact. This owner isolation does not certify the source's broader global timer/tween pause semantics.
