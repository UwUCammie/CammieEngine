# v0.0.25 security review

11 October 2026. User-requested review before publication. This is a scoped source, workflow and antivirus review, not a guarantee that all software or third-party mods are malware-free.

## Earlier incident

Commit `610bde166a9791b8ff61d663e834434026acf32f` added `.github/workflows/security-audit.yml`. Despite its name, it searched the checkout and Git history for credential patterns and attempted to send matches and context to an external HTTP endpoint. Commit `2dfe2f1c` reverted it. The code was inspected as data and was not executed locally.

GitHub still records the old successful run, `37855789273`, dated 8 October 2026. The current remote `.github` tree contains only issue and pull-request templates, and the workflows API returns no workflows. The returned run history contains no newer recurrence. Actions remains enabled at repository level; no repository or system security settings were changed. Local Git hooks contain no active non-sample hook, and no custom hooks path is configured.

A fresh scan of all locally reachable Git history covered 3,188,726 patch lines and found zero matches for the credential patterns targeted by the old workflow. The current tracked/untracked non-ignored text check also found zero credential-pattern matches. Only counts and locations are reported, never secret values. The earlier redacted audit also recorded no matches in the executed checkout or run logs. These checks provide no evidence of credential capture; they cannot establish what the remote endpoint actually received or recover unrecorded payloads.

## Current source and execution surfaces

- Static pattern review covered 2,795 tracked and non-ignored text files, including source, executable scripts, configuration and documentation. It checked the old logger indicators, credential stores, common exfiltration endpoints, encoded execution and persistence/security-disabling commands, and inventoried network hosts.
- Matches were reviewed in context. They were ordinary local-state comments, file-upload API declarations, graphics upload methods, tests, browser URL validation, the HTTPS GitHub updater and the source-compatible image downloader. No current credential collector or suspicious outbound destination was found.
- The launchers, packaging rules, tool download script and updater network/process entry points were inspected. Packaging uses committed clean registries and options, filters developer imports/caches and writes release metadata. Existing updater downloads are restricted to the project release path; source image downloads are GET requests.
- Supplementary indicator searches covered local Haxelib script/configuration files and the pinned Lime source. The returned matches were documented OpenFL file-upload APIs and Away3D GPU upload methods, not credential exfiltration.
- Microsoft Defender custom scan covered 3,318 staged project executable/configuration files and Windows build-tool executable/library/script files from the toolchains used here. It exited zero and reported no threats. `-DisableRemediation` was used, with no security configuration change. Definitions were dated 11 October 2026.

Evidence: `tmp/v25-security-static.json`, `tmp/v25-security-staging.json`, `tmp/v25-security-history.json`, `tmp/v25-antivirus-source.log`, `tmp/v25-github-workflows.json` and `tmp/v25-github-runs.json`. Package scanning and exact archive validation are recorded in the release validation report.

The scan does not reverse-engineer every dependency binary or inspect every ignored historical test installation, arbitrary donor mod, personal file or external system. The removed malicious workflow remains visible in Git history for auditability; it is absent from the current checkout and release.

## Final package result

Defender skipped the direct 723,949,657-byte ZIP scan, so its freshly extracted contents were scanned instead. That custom scan exited zero and explicitly reported no threats. Archive CRC, path/default checks and runtime hash comparisons passed. The archive has the same file list as v0.0.24; only Funkin.exe changed among executable/library/script surfaces. The extracted package then passed the muted native menu and pause checks. See `v0.0.25-release-validation.md` and `tmp/v25-antivirus-extracted-release.log`.
