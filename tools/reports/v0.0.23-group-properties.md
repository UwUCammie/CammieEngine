Group lookup preserves the source's initial direct field read, followed by tagged/nested traversal when the group path contains dots. Group member paths use literal dotted field names rather than ordinary property's bracket parser. Final map reads use raw source keys; group writes use Reflect property writes, preserving that source asymmetry. Integer fields on array members use indexing. Missing array members retain source null/no-write behavior; typed-group access follows the source direct-member route.

Removal retains the historical dontDestroy argument, kill/remove/destroy order, and repeated live root reads. An actor's kill hook can replace the active group before removal. Array removal removes the first matching item and does not destroy it, even when the selected index pointed to a later duplicate. The existing native group and receptor-bank removal operations are reused.

Class paths reuse shared raw map/array traversal and return true after successful writes. The existing class resolver remains available; six fully qualified historical aliases now share one table between Lua and HScript: PlayState, GameOverSubstate, Conductor, ClientPrefs, Paths and CoolUtil. These aliases point to the existing native/owner objects. This does not certify every source class name or every static field.

No donor edits, chart-specific branches or duplicate group implementation were added.
