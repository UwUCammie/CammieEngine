## Source and implementation

Pinned Psych revision `5c67ced49e5a98535298a6daa3f8f4ec79ac8399`: ReflectionFunctions.parseSingleInstance, parseInstances/parseInstanceArray and LuaUtils.getVarInArray with its default allowMaps=false.

The shared reflection service now distinguishes Lua setVar's single-value conversion from reflection callbacks' recursive argument conversion. It preserves the source length/delimiter recognition, final class suffix, trimmed dot tokens, PlayState.instance root and raw bracket indexing. Plain fields on MusicBeatState instances consult the live variable map, falling back to the actual property when the stored value is null. Bracket lookup consults the live variable map regardless of receiver type; a present null entry does not fall back to the receiver's field. Repeated registry reads remain live.

PsychInstanceArguments connects those common operations to real native state objects. Reflection callbacks retain interpreter-scoped class field routes; source Lua setVar uses the host's existing class-name resolver. Historical NV keeps the previous explicit-marker recursive extension, avoiding an unrelated dialect change. The shared native renderer, objects and class adapters remain in use. No donor/chart-specific changes were made.

## Differential and platform evidence

The test extracts the exact pinned source methods, using injected state/class/property boundaries on both sides. It compares ordered property/registry/class reads, results and failure outcomes for 224 cases on Haxe eval and again on native Windows C++. Cases include scalars, nulls, arrays, nested arrays, long non-sentinel strings containing delimiters, class suffixes, whitespace, absent/null registry entries, malformed brackets and registry changes during repeated reads. Failures are compared as failure outcomes, not exact exception text.

The Haxe eval target rejects some casts that native Windows handles. The source and implementation agree within each target; unrelated older reflection fixtures explicitly exercise the historical extension instead of assuming eval's scalar behavior proves the Windows contract. Public compiled-game probes cover native scalar conversion, null fallback, global bracket precedence, class paths, source delimiter recognition, recursive input preservation and native constructor arguments.

## Remaining requirements

This does not establish complete current-Psych reflection parity. Source class-name resolution still passes through existing compatibility aliases and owner-scoped routes; exact unknown-class/case failure behavior needs a separate audit. Public property get/set traversal, method invocation, default/optional argument handling, object helpers/constructors' live registry publication and scene ownership, full state transitions and teardown remain open. Historical NV and current NV retain their separate profiles. Continue those contracts and all previous compatibility/API, imported menus, library/Freeplay/categories/favorites/sorting and fidelity-preserving performance requirements.
