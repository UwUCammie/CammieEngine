## Source contract and shared implementation

Pinned Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx`: `callOnScripts`, `callOnHScripts`, `callOnLuas`, `setOnScripts` and `callScript`.

The historical source owns three independent writable arrays. Calls retain the selected array and iterate it live: insertion, removal, reversal and replacement have ordinary Haxe array iteration behavior. Default combined calls append event-map entries to the actual main array, including duplicates, before applying current type/event-name exclusions. Family and explicit-array calls do not append those entries. String selection retains duplicate names; callScript ignores halt and special filtering. Setters visit the selected live array without filtering.

`NightmareVisionLegacyScriptRegistry` keeps those decisions around the existing shared broadcast policy. HScript entries remain existing Iris modules; Lua handles delegate to existing LuaCompatInterp scopes and own no additional VM. Existing group loaders register before execution, unregister on failed initialization/removal, and notify the registry when releasing modules. Gameplay source bindings share writable array and method identity through bare, instance, class and reflection access. Existing historical hit/miss notification routes use these arrays.

The preceding timestamp/snapshot merge has been removed, including its counter and backend methods. Modern group broadcasting and ordinary Psych dispatch keep their existing behavior. Native smoke probes isolate and restore all new registry state.
