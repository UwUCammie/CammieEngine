# v0.0.27 user-library foundation and Freeplay favorites

12 October 2026. This advances the non-chart roadmap. It does not complete the library-management or Freeplay-redesign gates.

## Implemented behavior

- `UserLibraryData` owns versioned categories, many-to-many mod memberships, chart favorites and separate difficulty-name preferences. Category rename/deletion and membership removal do not remove favorites, difficulty history, files or other memberships. Category views are detached copies. Category filters use union semantics.
- `UserLibrary` stores this metadata in a dedicated FlxSave (`CammieEngineLibrary`, path `CammieEngine`), independent of imported registries and the active score slot. It clones edits, publishes them only after a successful flush, retains previous in-memory data after a failed write and reports errors in Library actions. Unsupported or malformed stored documents remain protected from edits instead of being overwritten with defaults.
- Chart keys reuse the retained importer owner and source-folder identity. Display labels and regenerated destination names do not enter imported chart keys. Base songs occupy a separate namespace. Windows case rules are preserved. Provisional rows, Random Song, Sound Test and unresolved imported receipts cannot become favorites. Cached per-row keys avoid repeated identity reads while filtering.
- Freeplay exposes Library actions on Tab or controller Select/Back. The actions favorite/unfavorite the installed selected chart and toggle favorites within the current category/owner view. Favorite filtering composes with existing song/mod search and uses the existing row window and readiness/launch guards. A `[FAVORITE]` label is separate from difficulty stars.
- Empty favorites/search results hide stale score details and cannot launch a hidden selection. Returning to all songs restores the visible list.

## Category management checkpoint

The shared Library action presentation now provides bounded category and mod lists.
Create, rename and delete categories; add/remove the selected imported mod or edit
multiple memberships in the installed-mod list. Package enumeration reuses
`ImportedModDiscovery` lazily, once per management session. Missing installed owners
retain their saved membership and can be removed explicitly. Category deletion has
a Cancel-first confirmation and changes only host metadata.

Category filters use a union, composed with favorites and text search within the
current Freeplay view. They preserve the existing authoritative Imported registry
and readiness guards. Windows owner spelling and slash variants share one membership.
Name entry supports keyboard typing and a controller-accessible character grid;
control characters are rejected. An opening-frame guard prevents cached parent
Accept actions from activating a new child menu.
