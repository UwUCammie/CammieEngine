# Fog unused-call performance probe

Local v0.0.24, 10 October 2026. Diagnostic evidence only; no production optimization was added.

## Hypothesis and isolation

The measured expensive fog program constructs two fractal-noise components, but its gradient consumes only the second. A scratch candidate replaced the unused first component with zero, leaving the consumed arithmetic unchanged. This tests whether the driver already eliminates that work before considering a general engine transformation. The authored shader was read only and never modified. No chart/mod-specific production branch was introduced.

The existing archived native comparator ran muted on a never-activated private Windows desktop, with authored uniform values, a 3180 by 1720 solid input and a 1280 by 720 comparison window. Production source and binaries were not replaced. Timings used one full-window sprite, a 60 FPS cap and asynchronous GPU elapsed queries. No build, test or independent hashing overlapped the timed controls.

## Results

Eight fixed-input comparisons at 0, 1, 10, 80, 175, 230, 999 and 3600 seconds produced zero differing RGB pixels across 441,600 pixels per capture. The image at 80 seconds was visually reviewed and shows the actual fog, not an empty fallback. The bottom 30 rows containing the MUTED overlay were excluded.

| Run order | Variant | Samples after frame 120 | Median GPU ms |
|---|---|---:|---:|
| 1 | Original | 545 | 0.19096 |
| 2 | Unused component removed | 544 | 0.19100 |
| 3 | Unused component removed | 542 | 0.19100 |
| 4 | Original | 546 | 0.19100 |

All four controls completed with zero skipped queries. There is no useful saving. This supports the driver already removing the unused component; it does not establish that all drivers do so. Do not add this transformation or claim a speedup from this experiment.
