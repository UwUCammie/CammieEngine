# v0.0.44 release validation

This user-authorized incremental alpha widens V-Slice, Psych and Nightmare Vision support at the engine, compatibility and importer level, fixes import recovery after the game folder moves, restyles the main menu, options and importer in Freeplay's design, adds the Import entry to the main menu, and updates the title logo with a colour shine. Remaining roadmap requirements stay open.

## Build and regression evidence

The final Windows build completed successfully. Its executable SHA-256 is `7d261f6a952b1d6ffdd5109686b529c719a81538eb3b8a239a79b8441b5d1c93`.

The full suite executed 3,553 tests across 1,214 modules in 673 seconds with 347 fixture/platform skips and zero failed modules, through `run.bat package`. The first gate attempt failed only on the title logo test, which looked for the development heading of the update log; it now accepts the released heading too.

Before packaging, the tests for every changed file passed (3,275 tests across 1,119 modules) and a whole-project type check passed.

## Native checks

Muted runs on a private, never activated desktop against private copies of a real install, 45 seconds each, with no frame over 300 ms in any run:

- Expurgation (Tricky Clowned Out, V-Slice) starts after its cancelled countdown, its character scripts attach, the health bar glow shows, the signposts and health-drain creature appear at their cues, and receptors no longer stay lit. In botplay the player dies at about 22 seconds.
- Satin Panties (Sonic Mix) shows the Erect limo stage, and Windbreak plays Boyfriend's vocal track.
- Ugh (FNIA add-on) places Boyfriend at (770, 450) as Psych does and shows the base mod's health icons.
- BATCOH's camera finishes a focus switch in about 1.3 seconds instead of never, and another Psych song's camera now settles at Psych's rate.
- One Nightmare Vision song and one plain Psych song play without new errors.
- The title screen shine, main menu, options and importer were captured in screenshots.

Not verified natively: QT Rewired's scripted speaker sprite (a mod-defined sprite class, not yet supported), FNIA Ugh's intro cutscene video, and Nightmare Vision camera rates (covered by unit tests).
