# v0.0.31 Freeplay navigation verification

Main-menu Freeplay now enters the host chart browser directly. Registry song collections remain available through Library actions, alongside favorites, category filters, and independent grouping/sorting. Imported caller return paths retain their existing routing.

Held Up/Down makes an immediate single step, waits 280 milliseconds, then repeats at 10 visible charts per second. Shift changes that rate to 30 while already holding. Opposed direction inputs and blocked browsing reset the repeat timer. Individual frames contribute at most 100 milliseconds, discarding a stalled frame's backlog. Ordinary 30, 60, 144, 480 and 1000 FPS probes produce identical repeat counts.

The selected chart's center aligns with the viewport center. Moving up starts 18 pixels lower; moving down starts 18 pixels higher. Exponential elapsed-time settling returns it to center. Settling adjusts only materialized rows, icons and star positions, without rebuilding ordering or reading analysis/score metadata each frame. Materialized windows leave blank space at list boundaries to keep selection centered.

Each difficulty star retains the shared rating color/shadow presentation and now displays an integer X/20 label. The selected card adds its difficulty-name label; 48-pixel grid strides reserve space for both lines.
