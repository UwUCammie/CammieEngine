# Psych source state timing checkpoint

Development version: 0.0.23, local only.
Source: Psych 1.0.4, revision `5c67ced49e5a98535298a6daa3f8f4ec79ac8399`, `source/backend/MusicBeatState.hx` and `MusicBeatSubstate.hx`.

## Change

Source construction through Iris and scoped reflection retains the native MusicBeatState identity and selects source timing per instance. Ordinary native states, PlayState and chart editing retain their existing timing. Fractional/section fields now live on the shared parent with their original zero defaults. Native gameplay still delivers every crossed step, subject to its existing catch-up limit.

Psych states and substates reuse `PsychBeatClock` for raw-time BPM selection followed by live noteOffset and fractional step calculation. They reuse `SourceBeatSections` with NV for section traversal. Source-created states expose the live source controls provider through shared source property views, plus elapsed state clock and fullscreen-save update. Native typed controls remain unchanged. Source state clock callbacks do not emit host NV plugin notifications.

Factory installation preserves existing constructor services and repeated installation does not stack wrappers. Source state camera initialization, transition APIs and stage callback traversal are not implemented by this checkpoint. The host remains a FlxUIState; native scene lifecycle equivalence is not claimed.

## Verification scope

The source comparison executes the pinned state clock methods with an empty stage traversal and compares six scenarios (three note offsets and null/non-null charts), each with twelve updates. It covers BPM boundaries, fractional steps/beats, forward sections, rewinds, stationary time, elapsed state time and nullable fullscreen save data. Class-scope checks verify live source controls, cross-interpreter reads, raw field access, repeated installation and preserved constructor delegation. Existing substate source comparisons and native catch-up regression remain required.

The native probe constructs actual source states through Iris and scoped reflection in a disposable muted private-desktop runtime. It checks native identity, source controls, host isolation, fractional timing, section traversal and rewinds. These are unmounted state checks hosted by a gameplay fixture, not imported-menu acceptance.
