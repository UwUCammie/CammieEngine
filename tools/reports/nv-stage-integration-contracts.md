## Source contracts and implementation

`funkin/objects/Stage.hx` constructs an actual `FlxTypedContainer<FlxBasic>`, builds data objects, and searches five script candidates in order. Its `runScript` executes a real module with the supplied group's shared map before injecting `add`, `stage`, and named objects. It invokes `onLoad` before the caller registers that same module. Syntax and top-level execution failures are both `parsingFailed`; preset/binding failures propagate outside that boundary. The donor's third-position shareables argument skips the optional typed Boolean through Haxe optional-argument resolution; it is not a signature defect.

PlayState now exposes actual typed `stage`, `scripts`, `eventScripts`, and `noteTypeScripts`. The real Stage is one mounted scene unit and owns its props and accepted role groups. The existing `curStage` remains a host metadata/other-engine bridge, without flattening NV Stage children into the state. `onAddSpriteGroups` STOP leaves the Stage and role groups unmounted; source scripts may mount them explicitly. Public pointer replacements do not mount, reconcile, rebind, or destroy prior values. Backend script dispatch follows the current public group pointers, including authored null failures.

Actual source `FunkinScript` imports and runtime names resolve to the real module Class. Its public `call` returns the genuine `crowplexus.iris.Iris.IrisCall` result, and internal gameplay/plugin/modifier consumers use explicit `callValue`. Public `execute` runs stored source again and returns its result without clearing an earlier parsing exception. `executeFunc` preserves source extra-variable map mutation and restoration of absent variables as null entries. Standalone source constructors and `fromString`/`fromFile` do not register with a ScriptGroup or invoke `onLoad` automatically. Filename defaults and inferred/explicit `modFolder` are established before preset and execution; the module's field is authoritative for the preset variable.

Captured Paths owns the script extension array and executed-instance name map. Constructors suffix names against already executed instances before parsing, but unexecuted same-name handles do not reserve a name. Execute registers the handle before its program runs; destroy removes that name without destroying a different handle. ScriptGroup shareables pointer assignment does not rebind existing members; changed/null parent assignment propagates the current pointer, while same nonnull parent assignment returns early.

Standalone preset configuration selects the current matching owner PlayState, otherwise the current non-gameplay state. Stage file configuration avoids a live Game.stage binding that would shadow the later Stage-specific injection. Stage's class map and constructor closures are retained independently from the creating interpreter, through the original provider lease. Same-owner retained Stage construction/loading survives creator destruction; actual owner exit rejects before IO and cannot create a fresh old-root provider.

Sparrow/Packer/general atlas lookup follows pinned `funkin/Paths.hx:355-444`: cache first by resolved PNG path without extension, Sparrow then Aseprite then Packer, null missing metadata, and caching only nonnull results. Atlas release drops borrowed references. Animate atlas eviction translates the known native owner-key prefix to the source asset key and removes only the canonical atlas/tracked rows; it does not scan graphics by identity or evict sibling-owner/author alias entries.

Stage custom Character construction uses captured Paths before definition/image IO. The Bopper-family operation bridge invokes actual typed atlas/prefix/indices helpers and existing virtual offset/play methods. Its source animation offsets use shared scale/rotation/skew drawing math while preserving the hitbox offset after Stage.updateHitbox; native, Psych, Codename, and V-Slice presentation routes retain their existing behavior.

## Explicit host stage switching

NV `swapStage` is a host compatibility API, not a donor method. Availability is checked through retained owner stage data or a name-specific script before callbacks/mutation; the common fallback script alone does not establish availability. It removes and destroys only the old registered Stage module, transfers supported role groups actually present in the old container, destroys old owned props through native container ownership, and restores the original mounted state and outer slot. Group transforms/cache/actors survive. Detached groups and map-only actors are neither adopted nor destroyed. Independent role-position metadata is updated; global initial `onAddSpriteGroups` is not replayed. Errors after availability validation retain the partial progress of this explicit host sequence; it is not an atomic rollback API.
