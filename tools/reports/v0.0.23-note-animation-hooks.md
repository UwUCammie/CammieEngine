# Historical note animation hooks

Local v0.0.23, 9 October 2026. No push or publication.

## Source contract and shared implementation

Pinned NightmareVision revision: `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/Note.hx`, `reloadNote`, `loadNoteAnims`, `loadPixelNoteAnims` and `_loadNoteAnims`.

Historical atlas and pixel reloads now invoke their type-local animation hook after assigning frames and before finalizing antialiasing, pixel offsets, hold scale and the previous animation. Hooks use the existing owner module, receiver and temporary `super` support in `executeFunc`. Omitting `super` replaces the defaults; callback errors do not invent a fallback. The source's pixel admission condition is preserved: the pixel name must exist while the normal hook must be callable. This differs from simply testing whether the pixel hook is callable.

One historical adapter installs source color aliases, source prefixes, 30 FPS defaults, wider-key aliases and source integer sizing. It maps the active lane's resulting animation into the engine's shared note renderer, retaining custom frames, rate, looping and flips. Pixel defaults use the existing Psych-family `SourcePixelNoteFrames` implementation. Atlas callbacks run before modern JSON metadata validation can reject a custom historical atlas. The modern NV path remains separate where its source contract differs. No chart/mod branches or donor edits are involved.

## Remaining contracts

This checkpoint does not certify whole-chart parity, every animation-name query, historical source-created/recycled notes or full seven-key native gameplay. The host still uses direction-independent animation names internally. Native generated callbacks are synthetic source scripts over retained assets, not a claim that every authored custom note type has been played through.

Next implement the connected noteskin `noteSplash(offsets)` and `quants()` callbacks and historical splash constructor/setup overloads. Pinned `PlayState.spawnNoteSplash` builds per-key offsets, calls `noteSplash`, calls `quants`, chooses the quant prefix and color inputs, then sets up the pooled splash before broadcasting `spawnNoteSplash`. The historical constructor takes `(x, y, note)`, and setup takes `(x, y, note, texture, hue, saturation, brightness, field)`. Compare source field spacing, repeated setup scale multiplication, animation selection/rates, HSL mutation and completion against the shared splash pool. Source hardcoded song exceptions must not be copied into compatibility code; any supported equivalent must be expressed through general authored data or script behavior.

Other Phase 2 gaps and all later custom menu, library management, categories/favorites, Freeplay design, icon/star, independent sorting and fidelity-preserving performance goals remain open. v0.0.23 stays local until the complete roadmap and exit gates pass.
