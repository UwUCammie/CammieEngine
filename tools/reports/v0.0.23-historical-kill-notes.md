## Source and implementation

Pinned Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx`, KillNotes; `source/gameObjects/Note.hx`, destroy.

The historical public KillNotes entry point uses the existing live script/reflection binding service. It walks the current active-note group from its first member, sets active and visible false, removes the note alias, kills it, removes it from the group and destroys it. The loop rereads the live group after callbacks. Finally it replaces unspawnNotes and the historical event queue with fresh arrays, preserving previously retained array references and leaving pending note objects undestroyed, as the source does.

KillNotes and duplicate-miss cleanup share one retirement function. Native group-removal observers run before field membership is detached. A field-only hook reuses the existing native detachment implementation without removing the host note a second time; normal field removal retains its prior behavior. This preserves the distinction between active group ownership and field membership without a second cleanup subsystem.

No production branches depend on a chart or mod, and donor sources are unchanged. The source's built-in callers are debug skip-to-end handlers; this checkpoint exposes the gameplay script method without replacing the host's unrelated debug controls.
