# Shared native sprite-base checkpoint

Local development v0.0.23, 10 October 2026. No push or publication.

## Implementation

Source subclasses of FlxText and FlxSpriteGroup now retain their native base types while using the same owner-aware callback lifetime as source FlxSprite subclasses. One SourceSpriteClassLifecycle implements dispatch, destruction guards, owner detachment and native resource cleanup. A build macro emits the small virtual-entry and explicit-super methods for each native adapter, avoiding three copies of lifecycle logic. The adapters retain native constructor signatures, text formatting/rendering, group traversal and nested transforms.

The exact callback surface is update, draw, updateAnimation, kill, revive and destroy. Before owner binding, adapter callbacks use the native implementation; after release they remain inert. Indexed/member conversion and source scope cleanup share the adapter interface and lifecycle registry. Native Flixel behavior continues to handle text fields, graphics, motion, cameras and group properties.

Text construction exposed a separate shared interpreter defect: super() used a four-argument closure. The reproducible HScript-ex patch now forwards the complete argument array to the existing superclass constructor routine. This preserves the six arguments used by FlxText, including font size and embedded-font selection.

All production changes are at the shared engine/compatibility layer. No chart/mod-specific branches or donor edits were added.

## Remaining scope

Raw member-array iteration/replacement, sprite-group recycling, additional native helpers, other native bases/virtual hooks, native-construction callbacks and general reentrant/multi-scene teardown remain open. The checkpoint does not establish full arbitrary-subclass or renderer pixel parity. All original API/fidelity, imported-menu, management, categories/favorites, dense Freeplay, icons/stars, independent sorting and fidelity-preserving performance goals remain required. The full-roadmap release gate is incomplete.
