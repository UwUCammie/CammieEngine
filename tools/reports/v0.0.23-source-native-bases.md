# Shared native core-base checkpoint

Local development v0.0.23, 10 October 2026. No push or publication.

## Implementation

Authored FlxBasic, FlxObject and FlxGroup subclasses now use native adapters alongside the existing FlxSprite, FlxText and FlxSpriteGroup adapters. All six share one lifecycle helper and generated native-super trampolines. Recursive traversal sees real native groups, property changes immediately affect traversal, authored kill/revive callbacks run, and killed members still release native resources. Non-sprite adapters do not expose sprite-only animation callbacks.

Owner release requested during native lifecycle dispatch is deferred until the outer callback returns. Repeated release during destruction is guarded. Callback exceptions unwind dispatch depth and preserve the error when cleanup succeeds. This is a bounded native lifecycle contract, not a guarantee for arbitrary callbacks or conflicting callback/cleanup exceptions.

Production changes are shared engine/compatibility changes. No chart/mod-specific branches or donor edits were added.

## Remaining scope

General callback/multi-scene teardown, conflicting callback/cleanup exceptions, native helper APIs, static/reflection behavior, selected compiled-stage identity and owner-specific native facades need further work.
