# Historical NV field scaling checkpoint

Development v0.0.23, 9 October 2026. Production changes are shared engine/compatibility code. No chart-specific branches or donor edits.

## Source contract and implementation

Compared against Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/gameObjects/PlayField.hx`. One shared helper handles scalar assignment, note membership, baseline capture and removal. Receptors preserve the source static-animation resize/restore sequence. Taps scale both axes; sustains retain their raw timing height. Removed notes restore their raw scale and the shared modifier baseline. Historical fields expose source `scale` and `swagWidth`; modern fields retain their existing layout behavior.

Historical splash placement uses the owning field's spacing and multiplies its existing scale by the field scalar, including the source's reuse/compounding behavior. Receptor entrances include the historical ten-pixel vertical movement, direction and existing timing. Source quirks such as zero/negative scalars and unchanged receptor modifier baselines are retained.

The native check exposed a Haxe target distinction: dynamic member access does not invoke the `defScale` property getter on C++. The helper now uses `Reflect.getProperty` for getter-backed baselines and frame width. Flixel point copies also use typed calls because its inline-only copy method is unavailable through native dynamic reflection. The parity fixture exposes the properties as getters too. The opt-in native smoke probe exercises the real field setter, checks live note scales and spacing, then restores the original scalar.

## Remaining scope

This is a scalar/membership checkpoint, not full historical coordinate parity. Entrance coordinates and modifier-space gameplay coordinates differ between source generations. They need a coordinated source profile rather than adjusting initial placement alone. Pixel head/tail sheets, historical splash constructor overloads, shader presets, remaining note-type lifecycle behavior, advanced Animate and embedded/custom libraries remain open. No whole-chart parity is claimed.

The public v0.0.22 release already exists; this subsequent v0.0.23 checkpoint is local development and must not silently replace that release.
