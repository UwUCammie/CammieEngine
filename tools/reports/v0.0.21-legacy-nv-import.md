# v0.0.21 legacy Nightmare Vision import checkpoint

8 October 2026. Development only; no release, tag or push. Work was performed without sub-agents. Donor/chart/mod files were not changed.

## Implemented contracts

- Auto recognizes older NV executables using the combined `Nightmare Vision Engine` and `meta.data.scripts.IFunkinScript` markers. Either marker alone is insufficient; inherited Psych version/pack/custom-event hints cannot override proven NV identity. Explicit import selection remains authoritative.
- Scanner, content-family ownership and core asset collection use the same container-proof helper. Unproven parents cannot supply a sibling core asset tree.
- The shared NV song adapter handles legacy `content/<package>/data/<song>` plus `songs/<song>/Inst.ogg`, as well as newer nested song layouts. Core-first/package ordering and package-local audio ownership are preserved.
- Psych runtime media discovery recognizes a bundled Python standard library by its files and encoding directory, preventing irrelevant package nesting from triggering its depth limit. Folder names alone do not exclude assets. Retained snapshots and explicit mapped assets remain unchanged.
- NV importer revision 11 marks older NV conversion receipts for regeneration. Development is v0.0.21, one patch above the verified downloadable v0.0.20 release.

Scanner discovery reports 22 candidates with 11 duplicates; conversion publishes 11 unique songs. Evidence: `tmp/v21-native-import-extended.log` and `tmp/v21-legacy-nv-final/tmp/import-extended.jsonl`.

The core includes a 630.9 MiB bundled application which is currently materialized in multiple package namespaces. Shared-core reuse remains a measured performance follow-up, without dropping unclassified retained files.

Final-executable gameplay checks on that imported output advanced for 20 seconds, exited 0, and remained muted/off-screen. A later audit of the runner found that its zero-cap run omitted the separate `unlimitedFPS` setting and was clamped to 60 FPS. These legacy gameplay runs verify 60 FPS only; they do not verify unlimited FPS. Evidence: `tmp/v21-final-play-60.log`, `tmp/v21-final-play-0.log` and the corresponding private runtime process logs.
