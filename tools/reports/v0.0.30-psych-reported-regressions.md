# v0.0.30 reported Psych regressions

All changes are in shared engine, compatibility, test, or packaging code. Donor charts, events, images and scripts are unchanged. Native gameplay uses muted private Windows desktops and isolated installs. The user's playing install was read only. Nothing was published.

## Changes and evidence

- Getter-backed Flixel group reflection uses the native getter instead of raw dynamic member access. Darkened Grave's original native access violation was reproduced and the candidate progresses through gameplay.
- Concrete Lua script origins preserve the selected asset owner through missing-video/countdown handoffs. Broken Inside advances after its unavailable source cutscene rather than remaining stopped.
- Historical Psych HScript Lua handles, callback registration, dynamically loaded Lua files and cross-script globals reuse the existing owner-scoped registry. Safety Lullaby loads its nested pendulum script without the original native crash. Lua-returned arrays use Lua indexing, including stringSplit and directoryFileList.
- Positional table.insert preserves the inserted record instead of appending its numeric position. The unchanged Minecraft chat event passes a standalone empty-list and populated-list update probe. Source scripts receive songLength when installed and before song-start callbacks.
- Psych GF-section performer routing follows the section's primary input side. New note hits supersede special poses as in Psych, and beats do not interrupt authored special animations. Breezy Plains HARD reaches the insane-turned and insane-battle variants and their sing/firing animations.
- Psych stage metadata honors hide_girlfriend while retaining the host-required actor reference. Character swaps preserve the source role's stage order, opacity and visibility, and assign the correct role. Play Animation uses the source actor-target mapping.
- The combined Psych receptor group indexes the actual live arrows and refreshes after style changes. Receptors and combo indicators are created only after onStartCountdown accepts. A blocked video intro therefore exposes empty groups to onCreatePost, matching Psych. Default receptor coordinates are published after creation to both ordinary and computed Lua globals without resetting private script state. Empty pre-countdown groups cannot freeze zero baselines. Host entrance tweens have separate property ownership, and source alpha/Y tweens cancel only the corresponding host tween.
- Backroom explicitly fades all opponent lanes out. Its authored PlayerNotesFade event hides player notes near zero and restores them at 48045.4 ms; the first player notes start around 48.9 seconds. A 40-second visible-player capture is not a valid acceptance test for this chart.
- Search input excludes the live mute/volume shortcut bindings, Ctrl and Alt combinations.
- Windows package manifests recognize current and historical official bundled-asset hashes. The new installer replaces unchanged official assets, preserves edited files and supports rollback. The installed old title logo matches an official prior hash. The v0.0.29 ZIP did include the new logo; the older installed updater preserved the old asset. That old helper cannot gain the new replacement behavior until manually updated from a package (or used for a subsequent update after receiving the new helper).
