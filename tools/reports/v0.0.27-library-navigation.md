# v0.0.27 global library navigation and difficulty preferences

12 October 2026. Host library work; chart and donor content are unchanged.

## Behavior

- The host Freeplay category chooser exposes global Favorites and user categories,
  including when only one authored registry category exists. Authored entries and
  the authoritative Imported collection remain intact. Virtual entries are not
  offered as editable content in the legacy Sort menu.
- Global views share `FreeplayDirectEntry` collection and `FreeplaySongOrder`
  ordering with the existing All route. Library mode deduplicates destination
  references across categories, keeps distinct owner-qualified songs separate,
  includes content registered solely in All, and excludes the Random row from
  visible/launchable library results. No registry is rewritten.
- Favorites/category/text filters reuse the existing bounded Freeplay row window
  and readiness guards. Empty views initialize without stale score details or
  hidden chart launches. Explicit imported menu scopes and Sound Test clear host
  library view state; an ordinary chart return retains it.
- Manual difficulty changes save the canonical name in the separate user library.
  Selecting a chart restores that name only if the current support list, authored
  menu difficulty order and actual chart file permit it. Missing/removed/ambiguous
  names use normal engine fallback and do not silently replace the saved preference.
  Numeric registry reorderings do not change the remembered difficulty. Merely
  browsing a chart does not write a preference.

- Final muted private-desktop probes passed at 60 FPS and unlimited FPS:
  `tmp/v27-navigation-native-accepted60.log` and
  `tmp/v27-navigation-native-accepteduncapped.log`. Actual menu input opened global
