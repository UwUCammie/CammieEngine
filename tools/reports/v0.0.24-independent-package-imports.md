# Independent-package import verification

Local v0.0.24, 10 October 2026. Tests run muted on a never-activated private Windows desktop, separately from the playing installation. No donor or chart edits.

## Completed

A fresh copy of the v0.0.23 release with the current development executable imported 25 real packages as separate user-selected requests. The corpus includes fifteen Psych-folder downloads (one detected as V-Slice), including a base/add-on pair, and ten separately selectable authored Nightmare Vision content packs. This is separate-receipt coverage, unlike the earlier single aggregate package. No package was duplicated merely to inflate the count.

All 25 imports succeeded through Auto and committed 25 retained manifests. Together they cover 35 roots, 263 songs and 54,553 owned paths. Each manifest's transaction receipt hash was verified during preparation. The initial installed files were hashed for a later output comparison. Initial imports totalled 775.516 seconds across separate process launches; this has no matched control and is not a speedup claim. Nonfatal dependency diagnostics remain recorded; successful conversion does not establish complete gameplay fidelity.

The fifteenth request initially exposed the shared bin/dist scanner issue, now fixed and verified. See `v0.0.24-import-distribution-boundary.md`. The full production build and 2,764-test regression suite passed, with 344 environment-dependent skips and no failures.

## Pending acceptance check

A diagnostic build was prepared to force an ordinary update refresh in this private installation, using revision 4 only in its archived diagnostic binary. It records the actual shared Freeplay owner/song readiness decisions, including pending chart-directory overlaps, and each final package release. Production revision 3 sources and binaries were restored and their hashes verified before launch.

Windows Application Control rejected process creation with WinError 4551 on both the first attempt and one unchanged retry. The executable never started; no timed refresh, readiness transition or output-equivalence claim is made for this new 25-package fixture. No security setting was changed. The private runtime executable/library were then restored to the production build. Its valid initial-import receipts remain at production revision 3.

The prior aggregate-library speed and bounded-handoff evidence remains valid, but must not be described as this independent-package test. Resume the prepared diagnostic when the normal Windows execution policy allows it. The existing verifier requires all 25 receipts to advance normally, exact file hashes or exact-semantic JSON equality, pending rows blocked, a mixture of ready/pending packages during progress, and all rows ready at completion.
