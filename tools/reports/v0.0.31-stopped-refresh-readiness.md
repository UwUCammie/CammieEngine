## Corrected state handling

- The coordinator exposes active refresh work separately from reservations held by stopped failures. Receipt inspection, active conversion, runnable handoffs, provisional rows, affected-owner/dependency reservations and chart-path overlaps remain launch gates.
- Once active work ends, an unrelated legacy owner uses the established chart/provenance fallback even when another package remains failed. Unresolved global recovery still blocks imported charts. This does not release the failed package or its dependent owners.
- Runnable main-thread handoffs use their own song-loading counts, activity clock and label, rather than the last worker's completed cleanup measurements. Blocked-only handoffs are not advertised as background work or as successfully completed. Stored diagnostics remain accessible through Import Settings.
- Final worker retirement advances the availability revision so a view cached just before completion cannot retain the active-work gate. Manual imports retain their separate progress UI ownership.
