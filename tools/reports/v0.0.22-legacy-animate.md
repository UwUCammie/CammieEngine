## Implemented boundary

`SourceLegacyAnimateController` separates historical playback from the existing Animate renderer. It preserves metadata frame-rate fallback, exact/prefix symbol selection, per-definition offsets, stage first-frame/loop/reverse parameters, index sequences, pause/stop, elapsed-time stepping and completion-before-pause ordering. Source quirks such as reverse Frame-minus-length and old-symbol reset ordering remain observable. Invalid/non-finite timing and invalid indices receive diagnostics rather than entering a nonterminating loop or invalid renderer access. Reload clears obsolete definitions deliberately instead of retaining definitions backed by a replaced atlas.

`NightmareVisionLegacyFlxAnimate` uses the installed shared renderer and its compact/full-name JSON accessors. Mutable atlas libraries and animation cursors are independent. Stage and named-instance transforms are applied separately. Constructor presets and qualified imports use existing interpreter-local native class routes; reflected anim reads use the same per-instance controller and are removed on destruction. Borrowed owner services remain valid only for their captured lifetime.

`SourceAnimateAtlasLoader` reads declared text/image identities through the captured owner Assets service. It uses the shared decoder, exact direct-child spritemap IDs, and an owner-specific cache namespace with unique mutable library instances. It does not convert logical filenames into guessed asset IDs or borrow another owner.
