# v0.0.27 authored Freeplay order

12 October 2026. Shared importer metadata and host library presentation only.

## Behavior

Psych imports read owner-local weeks/weekList.txt and week song arrays. Unlisted
week definitions follow in deterministic filename order. Nightmare Vision reads
data/weeks with a legacy weeks fallback and gives explicit data/freeplay.json
tabs precedence: each tab's fromWeeks sequence, then its explicit songs. First
occurrence wins. The shared reader bounds file count and bytes, rejects foreign
content roots/path traversal, tolerates missing or malformed optional metadata,
and never scans chart/media trees. Hidden weeks do not supply an authored rank;
their songs remain available through the ordinary host-library fallback.

Source song spelling uses Psych's existing normalization and NV's exact existing
sanitize implementation, now shared by its runtime facade and the importer.
Ranks are attached once per discovered owner and indexed by source folder, never
destination aliases. Generated registry rows carry optional numeric order.
Reusable discovery preserves the field. Psych/NV importer revisions advance to
12/16; common and unrelated engine revisions are unchanged.

Default chart order reassigns each owner's existing presentation slots according
to authored rank. Unlisted songs follow in registry order. This preserves default
group order and interleaved owner positions in flat lists without introducing a
non-transitive comparator. Registry arrays are never rewritten by sorting, explicit
alphabetical/metric/history modes are unchanged, and provisional rows do not claim
known authored order. The browser caches ordering and consumes registry metadata;
no donor reads are added during browsing. Selected chart/difficulty/readiness use
their original indexes.

## Remaining gates

This is owner-local ordering metadata, not full donor-menu emulation. Cross-owner
shared/global week precedence, custom script-generated menus, unlock rules and
authored menu acceptance remain separate contracts. A complete refresh/reinstall
lifecycle run with the new order field remains open; source clone/repeated
discovery and payload checks do not establish that broader gate. Preserve the
viewport/long-label, physical controller and user-review gates, safe uninstall,
imported title/main/freeplay flows and all original compatibility/performance
goals. Native navigation ran with background refresh and is not a performance
benchmark. No chart/mod edits or publication.
