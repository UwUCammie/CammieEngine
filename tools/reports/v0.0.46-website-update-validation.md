# v0.0.46 website update validation

This incremental alpha moves full downloads, future release updates and changelogs to https://uwucammie.com/cammie-engine/. It is the final GitHub distribution release. Source and issues remain on GitHub. Remaining compatibility and roadmap requirements stay open.

## Distribution and installation

The updater reads a versioned SHA-256 file inventory from the website, hashes only its listed installation paths, and stages changed or missing files through immutable content-addressed objects. Duplicate contents use one transfer. Changed files are transferred whole. The existing transactional installer waits for the game to close, preserves settings, imports and edited assets, and rolls back failed installations. A previous website inventory permits removal of unchanged retired runtime files; protected content is retained.

The website publisher reads only the tested release ZIP. It transfers absent objects plus the full initial-download ZIP, rejects replacement of versioned release directories, and verifies all uploaded objects, the manifest, sidecar and ZIP before changing the public latest pointer. Maintenance scripts stay outside the public root. nginx serves these files directly, with the changelog route internally mapped to the site document. The existing account and Burnout application was not changed or restarted.

## Build and regression checks

The canonical Windows build passed. The full package gate ran 3,487 cases across 1,216 modules in 1,114.9 seconds with 348 platform/corpus skips. Four modules stopped at native fixture compilation deadlines under parallel load: updater helper, import refresh manager, Psych asset profile native, and native directory listing. All four entire modules then passed sequentially: 87 cases, no skips. Their deadlines and assertions were unchanged; standalone compilation used eight compiler workers. Across the full run and retries, all 3,568 cases are covered with no unresolved failures. Logs are `tmp/website-update-package-gate.log` and `tmp/website-update-isolated-retries.log`.

The focused affected-file run passed 325 cases across 28 modules. The additional manifest-tampering case passed in its focused module and the full run. The Linux VPS also passed the activation/symlink and path-safety tests, including the activation test skipped for Windows symlink privileges. The first direct affected-file attempt used system Python 3.15, which is incompatible with existing FixturePath helpers; the accepted runs used the bundled Python 3.12.

The final ZIP was packaged after all isolated retries passed. It has 1,735 entries, size 725,955,515 bytes and SHA-256 `7596fc4f8d3d995f8e269b122805f13e6fe075f74146e766b062cc4b4f640f15`. Preparing the website objects read every ZIP member with CRC verification. The packaged version and release tag are 0.0.46 and v0.0.46. Packaged executable hashes match the native build:

- Funkin.exe: `ddd24ae5c854b87010b1c1584afceb2e0cdaf6a59ccdd7b86c1a777c8a9d14b7`

## Live native and HTTP checks

The production helper updated a private extraction of v0.0.45 to the website's v0.0.46 in 27.42 seconds on a never-activated Windows desktop. This used the newly built helper to exercise the website path. Options, imported content, a raw-source cache sentinel and an edited official asset were preserved. The installed game, updater and Lime hashes match the release inventory. No full ZIP was downloaded. nginx recorded 9 successful object requests totaling 50,891,354 bytes, about 93.0% less than the full ZIP. Manifest metadata adds a small transfer beyond those object bytes.

The updated installation then passed a muted Tutorial startup/gameplay check on a private desktop, with one success marker, one PlayState-ready marker, no failure marker and exit zero. The playing installation was never modified.

Browser checks confirmed the download card and rendered current and historical changelogs. The immutable ZIP and latest-download symlink return the expected ZIP signature and size; the immutable ZIP supports HTTP range responses. Checksums and manifest digests match. Existing home, account and Burnout pages and shared CSS/JS remain byte-identical; their health endpoint returns 200. Both nginx and the existing application remain active. The public website inventory contains 1,735 paths backed by 1,562 distinct objects.
