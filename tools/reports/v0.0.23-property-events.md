# Historical property events and text tags

Local v0.0.23 development. Publication remains gated on the complete roadmap.

## Shared implementation

Source: historical Nightmare Vision revision `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx`, `source/meta/data/scripts/FunkinLua.hx` and `Globals.hx`.

Set Property now uses the shared reflection service with the historical path policy: exact case/spacing, raw values, source map and intermediate bracket traversal, and a literal final property token. Nested roots resolve tagged objects before the live gameplay/game-over state. Single-field writes still target PlayState. Failures propagate before post-effect notifications. Existing source HUD aliases retain their native identity.

Historical text tags now have an independent registry. Object/sprite/text precedence and the getLuaObject text flag match the source; text helpers address text tags without replacing a same-named sprite. Text removal can detach and retain a tag for reattachment. The generic removeObject extension also removes text-only tags. Native/Psych paths retain their existing behavior.

No chart-specific production branch, donor modification or duplicate reflection subsystem was added.
