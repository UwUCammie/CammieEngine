# Shared native constructor checkpoint

Local development v0.0.23, 10 October 2026. This checkpoint follows the separately completed source push; no new publication.

## Implementation

The shared adapter generator now binds each native instance to its source owner before calling the native superclass constructor. Object initialization and sprite frame hooks use the same callback/lifecycle service as updates and rendering. A shared macro helper adds their native-super dispatch cases without duplicating callback generation. Constructor callbacks can reach the most-derived source override while explicit super calls remain nonvirtual.

Source construction and native callbacks now share a deferred owner-release boundary. A release requested during initialization waits for the complete source constructor to return. A disposed result is rejected before it can be published. Callback exceptions unwind the boundary; partially constructed adapters retain cleanup ownership until scope release. No ambient global construction context was introduced.

All production changes belong to the shared engine/compatibility layer. No donor, chart or mod-specific production change was made.
