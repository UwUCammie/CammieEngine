# v0.0.27 score and authored-rating sorting

12 October 2026. Host Freeplay/library and shared score access only; no chart/mod changes.

## Contract

Chart ordering now offers best score and authored difficulty rating in both
numeric directions. Comparison difficulty is a separate persisted name, defaulting
to normal for older saves. It never changes the selected chart's launch difficulty.
The sorting controls show that scope; flat-list headings and the selected-song
panel show the comparison mode/difficulty/value. Group order, group boundaries,
search, categories, favorites and import-readiness rules remain independent.

Ratings reuse FreeplayDifficultyRating's named, validated source metadata. Unknown,
ambiguous or unsupported difficulties remain unknown instead of borrowing a nearby
host index. No star count or score is converted to an authored rating. Different
rating scales form deterministic alphabetic blocks; only values on the same scale
are numerically compared. Missing values sort last in both directions. Ties retain
registry ordinal and stable chart identity. Random Song remains a pinned action
and receives no comparison value; provisional import rows likewise remain unknown.

Scores use the existing owner-qualified destination identity and the best-score
record category. Highscore.peekBestScore is read-only, unlike the legacy getScore
getter that can create zero entries. Absent records remain unknown; stored zero and
negative scores remain values. Existing legacy zero entries are not reconstructed
as proof of a completed play. Sorting compares saved raw host points, not normalized
skill or a claim that charts, judges and modifiers have equivalent scoring potential.

The browser reads existing difficulty-support maps and registry rating descriptors.
It adds no chart-file scans or score writes while sorting. The ordering cache avoids
repeated metadata/score reads during unchanged navigation. Comparison preference
changes invalidate the cache; score deletion invalidates and reapplies the view.
Menu recreation and committed import generation changes rebuild from current data.
The selected play difficulty, preview/launch identity and readiness indexes remain
separate from comparison data. Custom imported menu callbacks retain their own flow.
