# Psych source-stage construction checkpoint

10 October 2026, local v0.0.23. No push, tag or release.

The existing owner-scoped HScript class loader now observes explicitly bound native super constructors without replacing their native class identity. Source inheritance links exist during construction, and inherited `this` expressions retain the most-derived source object. Psych compiled-stage scopes use these hooks to register before native construction and invoke virtual `create` inside `super()`, including nested and callback-created source stages. No donor, chart or mod production branches were added.

Native initializer fields overwrite earlier pending assignments, while forwarded host properties retain them. Host attachment precedes forwarding. The adapter advances all owned stages to the post-create placement phase, including stages constructed afterward. Failed root construction removes its partial registrations and newly added scene members. Host teardown retains the owner scope until sibling callbacks finish, then releases it without replaying callbacks for inactive or removed roots.
