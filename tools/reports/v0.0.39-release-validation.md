# v0.0.39 release validation

This user-authorized incremental alpha moves cutscene skipping from Enter to Left Alt and makes two import tests report slow disks and real failures correctly. Remaining roadmap requirements stay open.

## Build and regression evidence

The final Windows build completed successfully. Its executable SHA-256 is `d5407c58ce8741f5deb667d6d8995ede2a7a1386b693d6f7f83e998d2fbc49ec`.

The full suite executed 2,899 tests across 982 modules in 420 seconds with 347 fixture/platform skips and zero failed modules, through `run.bat package`.

Two earlier packaging attempts for this release stopped on one failed module each, and both were timeouts in import tests rather than failures of what they check:

- `test_import_removal_manager.py` ran a Haxe interpreter probe with a 15 second limit. It takes about one second alone and exceeded the limit beside the build and sixteen other modules. The limit is now 90 seconds.
- `test_import_io.py` copies a 64 MiB file on a worker thread against fixed waits. It timed out once in the gate and once in twelve runs alone, then passed 190 further runs, so it trips only when the disk is busy. Its fixture also threw out of `main` while a worker was parked behind the gameplay lease, so the process never exited and the real message was lost. The fixture now prints the failure, cancels the worker and exits, and its waits allow for a slow disk. The scheduler itself polls and was not changed.

## Cutscene skip key

Unit checks cover the freshness rule for a press, the video cutscene fixture driven through the key class, and source checks that the skip path asks only for Left Alt and no longer reads Enter or Space.

A muted native run on a private desktop confirmed that the skip itself still works when triggered through the harness hook: an opening script video went from 1.5 s to 11.1 s of song time with its end callbacks run.

A physical Left Alt press was not exercised, because a hidden window receives no key events. Not verified natively: that Right Alt is ignored, that Enter pauses during a video, and that a lone Alt tap does not move focus to the window's system menu on Windows.
