## Remaining scope and limits

Physical controller review, broader viewport coverage and complete real import stress testing remain open. The overlay uses the verified pinned native C++ OpenGL path. Unsupported rendering paths use normal lifecycle presentation. Completed-work units have unequal execution costs; an individual blocking decode or authored script callback can pause the progress bar until it returns. The probe establishes visible movement during synchronous work and no nested gameplay/frame updates, rather than smooth progress through every imported callback.
