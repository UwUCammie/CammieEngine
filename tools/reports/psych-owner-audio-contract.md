# Psych owner audio contract

`PsychOwnerPaths` returns `openfl.media.Sound` for `sound`, `music`, `soundRandom`, `returnSound`, `inst`, and `voices`. It translates the full source key before adding `Paths.SOUND_EXT`, then decodes through shared `FNFAssets.getSound`. `inst` and `voices` use `formatToSongPath`, the explicit `songs` library, and donor postfix and `beepOnNull` behavior.

For `modsAllowed=true`, the direct owner mod override is checked first. The facade then resolves the donor's raw `assets/<folder>/<file>` ID in Lime's default library through `RuntimeOwnerAssetIdentity.acquire(owner, 'Psych Engine', 'package').resolveAssetId(id, 'SOUND')`. Cammie's library-qualified `Paths.file` value is kept only as a legacy/native fallback. This lets `modsAllowed=false` skip the raw mod override while still loading a source-compiled base asset from the selected owner's authenticated path. A found identity returns its verified owner path. Missing/type-mismatch results follow the donor's current-level-to-shared lookup order; explicit parent folders remain final. Native fallback is allowed only for `no-index` or `unclaimed` results. Unverified, unknown, or invalid identity results do not fall through to core assets.

The modern optional-Boolean call shape matches the pinned Psych wrappers. In Haxe, passing a Boolean as the second argument skips optional `path:String`, preserving the default `beepOnNull` value. The focused typed probe checks `sound`, `music`, `inst`, `voices`, and explicit-folder argument lowering. The facade also accepts the older String second argument on `sound` and `music` as an explicit library path.

`PsychOwnerSoundCache` keeps decoded Sounds and donor-style `currentTrackedSounds`, `localTrackedAssets`, and `dumpExclusions` per normalized owner root. Repeated facade construction for an owner reuses its cache. `clearStoredMemory` retains sounds used in the current tracking window and releases stale owner references. `dumpExclusions` uses the active host `SOUND_EXT`. Owner retirement drops only that owner's cached references; it does not dispose Sounds that active playback may still hold or clear the process-wide OpenFL cache. `PsychStandardServices` binds owner-local language translation through `PsychOwnerPaths.bindFileTranslation` for new and reused runtimes, and releases the sound cache on retirement.
