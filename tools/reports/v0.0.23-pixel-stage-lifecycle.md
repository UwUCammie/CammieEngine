## Source and implementation

Pinned NightmareVision source: `7f96eb3b5a60352413229bf134bd348b79ad5fe6`, `source/meta/states/PlayState.hx`. `setStageData` assigns `isPixelStage` at lines 420-423, initial setup calls it at 708-709 before stage building, and `switchTo` restores the stored stage value at 5645-5647. Flixel 6 uses `startOutro` for the corresponding state-exit opportunity.

The engine now seeds historical pixel mode from the selected Stage data before stage scripts, noteskin setup and note generation. The native pixel renderer and source `isPixelStage` property share one value. Bare, game-instance, imported class and reflected accesses use existing interpreter-local bindings; source calls cannot overwrite another owner's mode through a process-wide static. The existing class-property bridge accepts Psych and both NV class names and writes the same live value. Historical state outro restores stage data before the completion callback, including early startup redirects. Modern NV retains its existing UI-pack initialization and outro behavior.

No chart/mod name branches, donor modifications or duplicate renderer were added. Runtime stage replacement and the rest of `setStageData` remain separate source contracts; this change does not invent automatic mid-song note reload behavior.
