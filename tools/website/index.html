Smaller updates

Open Settings → Check for Updates in the engine. The updater checks your installed files and downloads only changed or missing files. It verifies each download and installs after you close the game. Settings, imported mods and edited assets stay in place.

Already on an older release? Update once through the final GitHub release, v0.0.46, or extract the latest ZIP from this page. Future releases and changelogs live here.

Still growing

Compatibility with Codename, Psych, V-Slice, Modding Plus and Nightmare Vision is experimental. Some features remain unfinished, and imported mods may behave differently.
